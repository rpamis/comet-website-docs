欢迎使用 **Comet** (`@rpamis/comet`)。Comet 提供两套相互独立的可恢复需求工作流：

- Native 用详细需求、完整目标规格、状态检查和验证证据服务**强编码模型**，但不规定固定计划、TDD 或审查方法；

- Classic 连接 [OpenSpec](https://github.com/Fission-AI/OpenSpec) 与 [Superpowers](https://github.com/obra/superpowers)，保留完整五阶段治理。

项目根配置决定 `/comet` 转发到哪一个入口。

## 三步上手

<Steps>
  <Step title="全局安装 Comet CLI">
    通过 npm 全局安装后，`comet` 命令在机器上任何位置都可用。

    ```bash
    npm install -g @rpamis/comet
    ```

  </Step>
  <Step title="在项目中运行 comet init">
    进入项目根目录并初始化 Comet。向导会让你选择安装范围（项目或全局）、Skill 首选语言和要安装的 AI 平台。

    ```bash
    cd your-project
    comet init
    ```

  </Step>
  <Step title="在你的 AI 编码工具中调用 /comet">
    打开 Claude Code、Codex、Cursor 或其他[支持的平台](/zh/platforms)，输入 `/comet`。新的项目级初始化默认配置 Native；已有 Classic 项目保持 Classic。`/comet` 只读取项目配置并进入对应的永久入口，不根据任务大小猜模式。

    ```bash
    /comet 你想做的事情
    ```

  </Step>
</Steps>

## AI 原生文档

你可以通过 MCP 把 Comet 文档站直接接入到你的 Agent，对话时可按需检索最新文档内容。

### 在 Claude Code 中使用

```bash
claude mcp add --transport http docs-comet --scope user https://docs.comet.rpamis.com/mcp
```

### 在 Codex CLI 中使用

```bash
codex mcp add docs-comet --url https://docs.comet.rpamis.com/mcp
```

### 在 Cursor / Antigravity 中使用

```json
{
  "mcpServers": {
    "docs-comet": {
      "url": "https://docs.comet.rpamis.com/mcp"
    }
  }
}
```

### 在 VS Code 中使用

```json
{
  "servers": {
    "docs-comet": {
      "url": "https://docs.comet.rpamis.com/mcp"
    }
  }
}
```
