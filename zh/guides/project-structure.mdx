Comet 把需求事实、设计计划、运行状态和用户生成 Skill 分开保存。

## 经典工作流目录

```text
openspec/
├── config.yaml
├── changes/
│   ├── <name>/
│   │   ├── .openspec.yaml
│   │   ├── .comet.yaml
│   │   ├── proposal.md
│   │   ├── design.md
│   │   ├── tasks.md
│   │   └── specs/<capability>/spec.md
│   └── archive/YYYY-MM-DD-<name>/
└── specs/<capability>/spec.md

docs/superpowers/
├── specs/YYYY-MM-DD-<topic>-design.md
└── plans/YYYY-MM-DD-<feature>.md
```

## Comet 配置和运行目录

```text
.comet/
├── config.yaml
├── skills/
├── runs/
├── bundle-authoring/
├── bundle-factory-plans/
└── bundles/
```

不同项目不一定都会出现所有目录。只有使用对应能力后才会创建。

## 目录职责

| 路径 | 职责 |
| --- | --- |
| `openspec/changes/` | 活跃 change 和归档 change |
| `openspec/specs/` | 当前主规格 |
| `docs/superpowers/specs/` | 技术设计文档 |
| `docs/superpowers/plans/` | 实施计划 |
| `.comet/config.yaml` | 项目级 Comet 配置 |
| `.comet/skills/` | 项目 Skill 池 |
| `.comet/runs/` | standalone Engine Run 状态 |
| `.comet/bundles/` | 已发布 Bundle |
