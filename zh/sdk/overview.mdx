Comet SDK 为 Skill 工作流保存执行记录、用户决定和验证证据，并提供中断后的恢复接口。你的平台继续负责模型请求、工具调用、Skill 加载和用户交互。

如果你希望 Agent 根据目标创建一套流程，从 [Comet Any](/zh/skill-creator/getting-started) 开始。需要在自己的产品中定义流程或接入宿主执行器时，使用本页的 SDK。

## 选择接入层

| 你要实现什么                                       | 使用哪个入口         |
| -------------------------------------------------- | -------------------- |
| 定义步骤、审批、并行依赖和恢复                     | Workflow Runtime     |
| 将流程、入口 Skill、规则和固定依赖组成可安装的应用 | Workflow Application |
| 在 Native 或 Classic 中增加团队工作                | 原领域的应用工厂     |
| 提供记忆、知识、上下文或其他能力                   | Plugin SDK           |

Runtime 管理 Run、Action 和 Wait。Application 在其上固定真实 Skill、模块、产物契约和安装身份。Plugin SDK 管理插件注册、安装、启用状态和能力调用；宿主决定何时把插件上下文交给 Agent。

## 安装与公开入口

需要 Node.js 22.16 及以上的 22.x 版本，或 Node.js 24 及以上版本。SDK 使用 ESM，并提供 TypeScript 声明。

```bash
npm install @rpamis/comet@0.5.0
```

| 导入路径                              | 用途                                           |
| ------------------------------------- | ---------------------------------------------- |
| `@rpamis/comet/runtime`               | Workflow、执行器、Store、审批与恢复            |
| `@rpamis/comet/applications`          | 应用加载、Skill 适配、产物检查、报告样板与分发 |
| `@rpamis/comet/applications/compiler` | 从确认方案装配应用及隔离产物验收               |
| `@rpamis/comet/applications/native`   | Native 扩展工厂                                |
| `@rpamis/comet/applications/classic`  | Classic full、hotfix、tweak 组合工厂           |
| `@rpamis/comet/applications/creator`  | 可恢复的创作流程和观测接口                     |
| `@rpamis/comet/plugins`               | 通用插件 Runtime、定义、存储和类型助手         |
| `@rpamis/comet/plugins/comet`         | 包含个人记忆与项目知识的 Comet 插件集成        |

导入基础 Runtime 不会自动启动 Agent 或装配 Native、Classic、个人记忆、项目知识。按实际职责选择入口。
