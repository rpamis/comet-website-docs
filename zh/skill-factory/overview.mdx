`/comet-any` 是 Comet 的 Skill Factory — 你只需描述想要的工作流，它会自动完成 Skill 的创建、验证、评估和发布。

## 什么是 Skill Factory

Skill Factory 是 Comet 的核心能力之一。它让你可以：

- **从零创建** — 描述目标，自动生成完整的 Skill 包
- **优化现有** — 读取已有 Skill，改进和增强
- **组合多个** — 将多个 Skill 串联成一个工作流
- **评估验证** — 通过结构化评估确保质量
- **发布分发** — 一键发布到任意 AI 编程平台

## 核心理念

<Note>
  Skill Factory 的设计原则：用户只通过 `/comet-any` 交互，CLI 命令是内部后端，不会暴露为用户主流程。
</Note>

### 基于真实证据

Skill Factory 使用 `find-skill` 解析本地真实的 Skill 内容，而不是从名称猜测能力。每个生成的 Skill 都有 `resolved-skills.json` 作为证据，证明它基于真实实现。

### Engine 驱动

对于多步骤、需要恢复、guardrails 或运行时评估的 Skill，会自动生成 Engine 包（`skill.yaml`、`guardrails.yaml`、`evals.yaml`），提供确定性执行语义。

### 人工审批

发布前必须经过人工审查和批准。Skill Factory 会展示完整的审查摘要，包括调用链、偏差、评估结果和就绪状态。

## 快速开始

### 1. 创建新 Skill

在你的 AI 编程工具中输入：

```
/comet-any 创建一个数据处理工作流，包含数据读取、转换和写入三个步骤
```

### 2. 优化现有 Skill

```
/comet-any 优化 my-skill，增加错误处理和重试机制
```

### 3. 组合多个 Skill

首先在 `.comet/skills.txt` 中定义偏好顺序：

```
data-reader
data-transformer
data-writer
```

然后调用：

```
/comet-any 将这三个 Skill 组合为一个完整的数据管道
```

## 输入与输出

### 输入

| 输入 | 说明 |
|---|---|
| 目标描述 | 自然语言描述你想要的工作流 |
| `.comet/skills.txt` | 可选，定义 Skill 偏好和调用顺序 |
| `<name>` 参数 | 可选，指定 Skill 名称 |

### 输出

| 输出 | 说明 |
|---|---|
| `SKILL.md` | 用户文档 |
| `reference/resolved-skills.json` | 真实 Skill 解析证据 |
| `comet/skill.yaml` | Engine 定义 |
| `comet/guardrails.yaml` | 安全约束 |
| `comet/evals.yaml` | 运行时评估定义 |
| `comet/eval.yaml` | 评估 manifest |
| `.comet/bundle-authoring/<name>.json` | Bundle 编辑状态 |
