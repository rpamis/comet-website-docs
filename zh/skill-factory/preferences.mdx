`.comet/skills.txt` 是 Skill Factory 的偏好文件。它不是严格白名单，而是告诉 `/comet-any` 你希望优先考虑哪些 Skill，以及默认顺序是什么。

## 文件格式

```text
brainstorming
writing-plans
requesting-code-review
verification-before-completion
```

## 规则

- 一行一个 Skill。
- 行顺序进入推荐调用链。
- 可以偏离顺序，但必须解释原因。
- 缺失候选必须让用户决定忽略、替换或安装。
- 歧义候选必须让用户选择真实来源。

## resolved-skills.json

生成物应包含：

```text
reference/resolved-skills.json
```

它记录：

- resolved Skill 名称。
- 来源路径或来源标识。
- 描述。
- hash。
- reference、rules、scripts、hooks 摘要。
- `sourceSummaries`。

<Tip>
  这个文件是“不是按名字猜的”证据。准备发布或审查时优先看它。
</Tip>
