## 三步轻松上手

<Steps>
  <Step title="全局Npm安装Comet CLI">
    从npm安装Comet CLI，使`comet`命令在您的机器上任何地方都可用

    ```bash
    npm install -g @rpamis/comet
    ```
  </Step>
  <Step title="在你的项目中运行 comet init">
    导航至项目根目录并初始化 Comet。交互式向导允许您选择安装范围（项目或全局）、选择Skill的首选语言以及选择安装的AI平台

    ```bash
    cd your-project
    comet init
    ```
  </Step>
  <Step title="在你的AI编码工具中调用/comet命令">
    打开 Claude Code、Codex、Cursor或任何其他[支持的平台](/platforms)，然后输入 `/comet`。Comet 会读取当前规范，检测你所处的阶段，并自动继续工作流程。

    ```
    /comet
    ```
  </Step>
</Steps>
