欢迎来到 **Comet** (`@rpamis/comet`) — 本章为经典Spec模式，Comet基于Agent Harness能力，将[OpenSpec](https://github.com/Fission-AI/OpenSpec) 和 [Superpowers](https://github.com/obra/superpowers) 连接起来，变成五阶段自动化工作流，在此基础上额外集成了[CodeGraph](https://github.com/colbymchenry/codegraph)，让长程任务工具调用和代码检索更省Token。在Comet中您无需记忆原OpenSpec和Superpowers中的Skill命令，只需使用 `/comet` 一条命令，即可将您的想法从提案、深度设计、实现、验证到归档，Comet具备自动阶段检测功能，让您可以随时从上次中断的地方继续开发。

## 三步轻松上手

<Steps>
  <Step title="全局Npm安装Comet CLI">
    从npm安装Comet CLI，使`comet`命令在您的机器上任何地方都可用

    ```bash
    npm install -g @rpamis/comet
    ```
  </Step>
  <Step title="在你的项目中运行 comet init">
    导航至项目根目录并初始化 Comet。交互式向导允许您选择安装范围（项目或全局）、选择Skill的首选语言以及选择安装的AI平台

    ```bash
    cd your-project
    comet init
    ```
  </Step>
  <Step title="在你的AI编码工具中调用/comet智能命令">
    打开 Claude Code、Codex、Cursor或任何其他[支持的平台](/zh/platforms)，然后输入 `/comet`。Comet 会读取项目状态，检测你的需求/功能所处的阶段，根据意图识别结果智能路由，并自动继续工作流程。

    ```bash
    /comet 你想做的事情
    ```
  </Step>
</Steps>
