`comet-state.mjs` 负责 `.comet.yaml` 状态操作。它是 Comet 恢复能力的核心之一。

## 常见操作

```bash
node "$COMET_STATE" transition <change-name> open-complete
node "$COMET_STATE" transition <change-name> design-complete
node "$COMET_STATE" transition <change-name> build-complete
node "$COMET_STATE" transition <change-name> verify-pass
node "$COMET_STATE" transition <change-name> verify-fail
node "$COMET_STATE" next <change-name>
```

## next 输出

`next` 会根据 `phase`、`workflow` 和 `auto_transition` 输出：

- `NEXT: auto`
- `NEXT: manual`
- `NEXT: done`

`auto_transition: false` 只影响是否自动调用下一个 Skill，不影响当前阶段已经完成的状态推进。

## 状态约束

`comet-state` 会拒绝非法状态转换，例如 full workflow 在缺少 build 必选字段时离开 build。它也会保护 machine-owned Run 字段，避免用户手工误改。
