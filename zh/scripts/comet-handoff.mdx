---

`comet-handoff.mjs` 负责把当前阶段的重要证据整理成交接信息。它服务于长任务、子代理执行和上下文恢复。

## 交接包包含什么

- 当前 change 名称和 phase。
- OpenSpec artifacts 路径。
- Design Doc 和 Plan 路径。
- 当前任务和未完成任务。
- 验证命令和已知证据。
- 子代理进度或恢复提示。

## 什么时候有用

- build 阶段任务很多。
- 使用 subagent-driven development。
- Agent 会话发生上下文压缩。
- 需要把当前工作交给另一个会话。

<Tip>
  普通用户不需要手工编辑交接包。恢复时先用 `comet status` 和 `/comet`。
</Tip>
