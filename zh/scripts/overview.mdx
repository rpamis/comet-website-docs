Comet 的内置脚本随 Skill 包分发。0.4.0-beta.1 中这些脚本通过 Node 运行，不再要求 Bash。

## 脚本职责

| 脚本 | 职责 |
| --- | --- |
| `comet-state.mjs` | 读取、写入和转换 `.comet.yaml` |
| `comet-guard.mjs` | 检查阶段门禁，并在 `--apply` 时推进状态 |
| `comet-handoff.mjs` | 生成阶段交接包 |
| `comet-archive.mjs` | 调用 OpenSpec archive 并完成归档收尾 |
| `comet-env.mjs` | 定位脚本目录 |
| `comet-runtime.mjs` | 共享运行时实现 |

## Agent 如何定位脚本

Skill 内会先定位 `comet-env.mjs`，再得到脚本目录。不要在文档或提示词里硬编码用户机器路径。

```bash
COMET_SCRIPTS_DIR="$(node "$COMET_ENV")"
COMET_STATE="$COMET_SCRIPTS_DIR/comet-state.mjs"
COMET_GUARD="$COMET_SCRIPTS_DIR/comet-guard.mjs"
COMET_HANDOFF="$COMET_SCRIPTS_DIR/comet-handoff.mjs"
COMET_ARCHIVE="$COMET_SCRIPTS_DIR/comet-archive.mjs"
```

## 日常用户要不要直接运行

多数情况下不用。普通用户优先使用 `/comet`、`comet status` 和 `comet doctor`。脚本主要服务于 Skill 内部流程和高级排障。
