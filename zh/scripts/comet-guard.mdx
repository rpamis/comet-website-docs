`comet-guard.mjs` 是阶段门禁。它会检查当前 phase 需要的文件、字段和验证证据。

## 基本形式

```bash
node "$COMET_GUARD" <change-name> <phase>
node "$COMET_GUARD" <change-name> <phase> --apply
```

不带 `--apply` 时只检查。带 `--apply` 时，检查通过后会委托状态脚本推进 phase。

## 常见检查

- open: proposal、design、tasks 和 delta spec 是否完整。
- design: Design Doc 是否存在。
- build: `build_mode`、`isolation`、`tdd_mode`、`review_mode` 等是否满足约束。
- verify: 验证报告和验证结果是否可用。
- archive: 是否已通过验证并完成最终确认。

<Warning>
  guard 失败时不要硬改状态绕过。先修复缺失证据或回到对应阶段。
</Warning>
