`comet-archive.mjs` 是归档阶段的确定性入口。它负责把通过验证的 change 移入 OpenSpec archive。

## 基本形式

```bash
node "$COMET_ARCHIVE" <change-name>
```

## 它会做什么

- 调用 `openspec archive <change> --yes`。
- 检查主 specs 中是否残留 delta requirement 标题。
- 标注相关设计文档状态。
- 更新归档结果。

## 重要边界

不要手工把 change 标记为 archived。OpenSpec archive 会创建带日期前缀的归档目录，手工 transition 容易造成状态和文件位置不一致。
