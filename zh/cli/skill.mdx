---
title: "comet skill"
description: "管理本地 Comet Skill 包，并运行 deterministic Skill Run。"
---

`comet skill` 是低层 Skill 包和 Engine Run 工具。普通用户创建可复用 Skill 时优先用 `/comet-any`。

## 子命令

| 命令 | 用途 |
| --- | --- |
| `install <path>` | 安装本地 Skill 到项目 Skill 池 |
| `validate <skill>` | 校验 Skill 包结构 |
| `inspect <skill>` | 查看 Skill 内容和元数据 |
| `run <skill>` | 启动 deterministic Skill Run |
| `resume` | 提交 pending action 的结果或恢复 Run |
| `eval` | 检查当前 Run 的 runtime eval |

## 包管理示例

```bash
comet skill install ./my-skill --project .
comet skill validate my-skill --project .
comet skill inspect my-skill --json
```

## Run 示例

```bash
comet skill run my-skill --run-id demo-run --project .
comet skill resume --run-id demo-run --status succeeded --summary "完成"
comet skill eval --run-id demo-run --scope completion
```

<Warning>
  `comet skill eval` 只检查某次 Engine Run 的完成度。评估一个 Skill 产品能力，请用 [comet eval](/zh/cli/eval)。
</Warning>
