title: 'comet application'
description: '导出、预览安装、分发、升级和选择性卸载完整 SDK 工作流应用。'
---

`comet application` 处理以 `application.json` 为入口的完整应用。它将应用包、固定依赖和平台 Skill/Rule/Hook 入口一起管理。

## 命令

| 命令                          | 用途                                 |
| ----------------------------- | ------------------------------------ |
| `install <file>`              | 预览或确认当前应用的本地安装         |
| `distribute <file>`           | 向所选 Comet 平台分发应用            |
| `export <file> <destination>` | 导出完整包及固定依赖                 |
| `uninstall <id>`              | 预览并移除应用平台入口，保留所需版本 |

## 预览与确认

```bash
comet application distribute ./weekly-report/application.json --project . --platform codex --preview --json
```

读取将要写入的目标、固定内容、能力与冲突。用户确认后，用本次预览返回的摘要继续：

```bash
comet application distribute ./weekly-report/application.json --project . --platform codex --confirmation-hash <本次预览确认摘要> --json
```

未提供确认摘要时，分发默认返回预览。包、文件或配置变化后，重新获取并确认预览。

| 选项                         | 作用                                      |
| ---------------------------- | ----------------------------------------- |
| `--project <dir>`            | 安装所关联的项目，默认 `.`                |
| `--platform <id>`            | 可重复选择平台；`all` 选择已登记的平台    |
| `--scope project`            | 项目级安装，默认值                        |
| `--scope user`               | 用户级安装                                |
| `--user-root <dir>`          | 指定隔离的用户应用目录                    |
| `--preview`                  | 只读取预览，不安装                        |
| `--confirmation-hash <hash>` | 提交已确认的当前预览                      |
| `--upgrade`                  | 更新平台入口，并保留活动 Run 使用的旧版本 |
| `--json`                     | 输出结构化结果                            |

平台安装能力以预览为准。缺少 Hook、需要宿主激活或无法加载所需 Skill 时，应先处理限制，不能把文件安装成功作为执行验收。

## 导出

```bash
comet application export ./weekly-report/application.json ./exports/weekly-report --project . --json
```

导出保留入口、模块和固定依赖。不要只复制 `SKILL.md`，也不要在不更新身份与确认的情况下替换包中的模块。

## 选择性卸载

```bash
comet application uninstall weekly-report --project . --platform codex --json
comet application uninstall weekly-report --project . --platform codex --confirmation-hash <本次卸载预览摘要> --json
```

省略平台选择时卸载全部入口。共享 Rule/Hook、其他应用的依赖和仍需使用的版本继续保留。

卸载中断后，使用原平台选择和 `--confirmation-hash` 重试，继续已确认的卸载计划。先完成这次卸载，再重新安装。入口文件发生变化时，先解决冲突，保留原卸载范围。

运行记录使用 [comet runtime](/zh/cli/runtime)，创作过程使用 [comet creator](/zh/cli/creator)。
