---

`comet application` 专职纳管以 `application.json` 为主契约入口的完整工作流应用。它统筹协调应用制品包、锁定的静态依赖版本以及各 Agent 平台的 Skill、Rule 与 Hook 资产分发。

## 核心子命令

| 命令形式 | 核心用途与能力 |
| --- | --- |
| `install <file>` | 在本地环境中预览或正式确认当前应用的安装 |
| `distribute <file>` | 将应用批量分发并注册至指定的 Comet 支持平台 |
| `export <file> <destination>` | 导出包含主应用及所有锁定依赖的完整分发包 |
| `uninstall <id>` | 预览并精细化移除特定平台入口，按需保留底层版本资产 |

## 两阶段安全预览与确认机制

```bash
comet application distribute ./weekly-report/application.json --project . --platform codex --preview --json
```

该命令会率先探查拟写入的物理目标路径、锁定的依赖内容、平台运行环境能力与潜在命名冲突。经开发者人工核准后，携带本次预览专属的防篡改摘要执行最终分发：

```bash
comet application distribute ./weekly-report/application.json --project . --platform codex --confirmation-hash <本次预览确认摘要> --json
```

若未显式提供确认摘要，分发指令默认回退为纯预览模式。一旦底层制品包、物理文件或环境配置发生任何微小变动，先前签发的摘要立即失效，必须重新拉取并复核预览。

| 选项参数 | 功能说明 |
| --- | --- |
| `--project <dir>` | 关联的目标项目物理根目录（默认值为 `.`） |
| `--platform <id>` | 目标平台标识符（支持多次指定；传入 `all` 自动匹配全部已登记平台） |
| `--scope project` | 采用项目级局部安装模式（出厂默认值） |
| `--scope user` | 采用用户级全局安装模式 |
| `--user-root <dir>` | 自定义物理隔离的用户全局应用存储目录 |
| `--preview` | 纯只读拉取预览差异报告，绝不执行物理写操作 |
| `--confirmation-hash <hash>` | 提交匹配当前预览结果的确认凭证，放行物理写入 |
| `--upgrade` | 安全升级平台入口，同时平滑保留在途活动 Run 正在消费的旧版本 |
| `--json` | 输出标准机器可读的结构化 JSON 报文 |

各 Agent 平台的真实执行能力以预览阶段输出的诊断结论为准。若检测到平台缺少必要的 Hook 扩展、需要手动在 Agent 设置中完成权限授权、或无法合法装载配套 Skill，请先排除上述限制，切勿单纯把静态文件写入成功误当成业务验收达标。

## 完整独立导出

```bash
comet application export ./weekly-report/application.json ./exports/weekly-report --project . --json
```

导出机制会完整封装应用主入口、关联代码模块与所有被锁定的静态 Skill 依赖。切忌只手动拷贝零散的 `SKILL.md`，亦严禁在未重新核验签名与应用身份凭据的情况下私自替换包内部件。

## 细粒度选择性卸载

```bash
comet application uninstall weekly-report --project . --platform codex --json
comet application uninstall weekly-report --project . --platform codex --confirmation-hash <本次卸载预览摘要> --json
```

若省略 `--platform` 参数，系统默认卸载该应用在全部 Agent 平台上的注册入口。共享的全局 Rule/Hook 规范、其他并行应用仍在共用的公共依赖、以及历史归档版本依然安全保留。

若卸载流程在执行途中遭遇异常中断，直接传入相同的平台参数与 `--confirmation-hash` 重试即可，系统会按既有卸载记录继续执行。建议务必先走完先前的卸载事务，再行触发全新安装。若检测到本地入口文件已被外部手动改动，必须先解决物理冲突，严格捍卫既定卸载范围。

生产运行态调度请参考 [comet runtime](/zh/cli/runtime)，全生命周期创作指南请参阅 [comet creator](/zh/cli/creator)。
