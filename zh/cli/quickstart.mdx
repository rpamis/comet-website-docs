本页是 Comet CLI 的最短上手路径。只需要三条命令就能完成安装、检查和恢复。想了解每个命令的完整选项，再看[进阶内容](#进阶内容)。

## 前提

- Node.js 20+
- npm/npx
- Git

<Info>
  0.4.0-beta.1 起 Comet 是纯 Node 运行时，不再需要 Bash、Git Bash 或 WSL。macOS、Linux、Windows 用同一套命令。
</Info>

## 第一步：安装 Comet

全局安装 CLI：

```bash
npm install -g @rpamis/comet
```

## 第二步：初始化项目

在项目根目录运行：

```bash
comet init
```

它会检测你的 AI 编码平台，安装 OpenSpec、Superpowers 和 Comet Skill。中文环境推荐：

```bash
comet init --scope project --language zh
```

CI 或脚本环境用非交互模式：

```bash
comet init --yes --scope project --language zh --json
```

<Tip>
  初始化后建议跑一次 `comet doctor` 确认安装完整。
</Tip>

## 第三步：日常用这两条命令

### 恢复工作流：comet status

会话中断后，先看状态再继续：

```bash
comet status
```

它会告诉你当前活跃 change、所在阶段和推荐的下一条命令。然后输入 `/comet` 继续，Agent 会从文件状态恢复，而不是靠记忆。

### 排障：comet doctor

如果 `comet status` 显示异常，或安装看起来有问题：

```bash
comet doctor
```

它会检查项目级和全局安装、平台目录、Skill、脚本和活跃 change 状态，并给出恢复提示。

## 升级和卸载

升级到最新版：

```bash
npm install -g @rpamis/comet@latest
comet update --scope project --language zh
comet doctor
```

卸载（保留你的 OpenSpec change、设计文档和代码）：

```bash
comet uninstall --scope project
```

## 常见问题

<Accordion title="comet init 安装到哪里">
默认检测当前项目的 AI 编码平台目录。用 `--scope project` 只装项目级，`--scope global` 装全局。
</Accordion>

<Accordion title="status 显示阶段不对">
先跑 `comet doctor` 看是否有畸形 `.comet.yaml` 或缺失证据。修复后重新跑 status。
</Accordion>

<Accordion title="Windows 上脚本能跑吗">
0.4.0-beta.1 起所有脚本都通过 Node.js 运行，Windows 不再需要 Git Bash 或 WSL。
</Accordion>
