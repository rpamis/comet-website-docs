`comet bundle` 是 `/comet-any` Skill Factory 的底层 CLI 后端，提供 Bundle 生命周期的细粒度控制。大多数用户应该使用 `/comet-any` Skill 或 [`comet publish`](/zh/cli/publish) 命令。

<Note>
  `comet bundle` 是高级命令组。如果你只是想创建和发布 Skill，请使用 `/comet-any` 或 `comet publish` 命令。
</Note>

## 子命令一览

| 子命令 | 用途 |
|---|---|
| [`comet bundle candidates`](#candidates) | 发现 Skill 候选 |
| [`comet bundle draft create`](#draft-create) | 创建空 Bundle draft |
| [`comet bundle draft optimize`](#draft-optimize) | 从现有 Bundle 创建优化 draft |
| [`comet bundle list`](#list) | 列出可恢复的 Bundle 编辑状态 |
| [`comet bundle status`](#status) | 查看 Bundle 编辑状态 |
| [`comet bundle factory-init`](#factory-init) | 初始化 factory 元数据 |
| [`comet bundle factory-resolve`](#factory-resolve) | 解析缺失/模糊的候选 |
| [`comet bundle factory-generate`](#factory-generate) | 生成 draft 源码 |
| [`comet bundle compile`](#compile) | 干运行编译 |
| [`comet bundle eval-plan`](#eval-plan) | 估算评估工作量 |
| [`comet bundle eval-record`](#eval-record) | 记录评估证据 |
| [`comet bundle review-summary`](#review-summary) | 构建审查摘要 |
| [`comet bundle review`](#review) | 批准或拒绝 |
| [`comet bundle publish`](#publish) | 发布到 `.comet/bundles` |
| [`comet bundle distribute`](#distribute) | 分发到平台 |

## candidates

发现项目中可用的 Skill 候选。

```bash
comet bundle candidates
```

### Flags

<ParamField query="--project" type="string" default=".">
  项目根目录。
</ParamField>

<ParamField query="--json" type="boolean">
  输出 structured JSON。
</ParamField>

### 示例

```bash
comet bundle candidates
```

```
my-skill: available
data-processor: available
api-wrapper: missing
```

## status

查看单个 Bundle 的编辑状态。

```bash
comet bundle status <name>
```

### Flags

<ParamField query="--project" type="string" default=".">
  项目根目录。
</ParamField>

<ParamField query="--json" type="boolean">
  输出 structured JSON。
</ParamField>

### 状态流转

Bundle 编辑状态按以下顺序流转：

```
draft → eval-passed → review-approved → ready
```

如果 draft 内容发生变化（hash 不匹配），状态会回退到 `drift-conflict`。

## factory-init

从结构化计划文件初始化或更新 Bundle factory 元数据。

```bash
comet bundle factory-init <name>
```

### Flags

<ParamField query="--project" type="string" default=".">
  项目根目录。
</ParamField>

<ParamField query="--file" type="string" required>
  Factory 计划 JSON 文件路径。
</ParamField>

<ParamField query="--json" type="boolean">
  输出 structured JSON。
</ParamField>

### 计划文件结构

```json
{
  "goal": "Create a data processing workflow",
  "preferredSkills": ["data-reader", "data-transformer", "data-writer"],
  "callChain": [
    { "skill": "data-reader", "preferenceIndex": 0 },
    { "skill": "data-transformer", "preferenceIndex": 1 },
    { "skill": "data-writer", "preferenceIndex": 2 }
  ]
}
```
