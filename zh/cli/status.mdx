`comet status` 是日常恢复和排障的第一条命令。

## 基本用法

```bash
comet status
```

| 选项 | 说明 |
| --- | --- |
| `--json` | 输出结构化状态 |

## 它会告诉你什么

- 当前是否有活跃 change。
- 当前 change 的 workflow 和 phase。
- 推荐的下一步命令。
- Classic runtime mode 和 current step。
- 缺失证据或畸形 `.comet.yaml` 的恢复提示。

## 推荐使用场景

```bash
comet status
```

如果输出显示异常，再运行：

```bash
comet doctor
```
