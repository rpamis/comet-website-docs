---
title: "comet uninstall"
description: "安全移除 Comet 安装的 Skill、规则和 hooks，同时保留用户自定义配置。"
---

`comet uninstall` 会移除 Comet 管理的文件。它不会故意删除用户自己的 hooks 或非 Comet 配置。

## 基本用法

```bash
cd your-project
comet uninstall
```

| 选项 | 说明 |
| --- | --- |
| `--force` | 跳过确认提示 |
| `--scope <scope>` | 仅卸载 `project` 或 `global` |
| `--json` | 输出 JSON |

## 示例

交互式卸载：

```bash
comet uninstall
```

仅移除项目级安装：

```bash
comet uninstall --scope project
```

非交互式：

```bash
comet uninstall --force --json
```

<Warning>
  卸载 Comet 不会删除你的 OpenSpec change、设计文档、实施计划或项目代码。
</Warning>
