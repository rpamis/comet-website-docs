`comet uninstall` 会从你的 AI 编程平台中安全移除 Comet 安装的 skills、rules 和 hooks，同时保留你自己创建的文件。

## 用法

```bash
comet uninstall [path]
```

省略 `path` 时，默认值为 `.`（当前目录）。

## `uninstall` 会做什么

1. **检测已安装 targets** — 扫描项目目录和 home 目录，查找已安装 Comet skills 的平台。
2. **交互式选择** — 如果找到多个 target，显示 checkbox 让你选择要卸载的平台；单个 target 则显示确认 prompt。使用 `--force` 或 `--json` 时跳过交互。
3. **移除组件** — 对每个选中的 target，移除 skills、rules 和 hooks（仅限支持 hooks 的平台）。
4. **清理工作目录** — 对 project scope，移除 `docs/superpowers/specs/` 和 `docs/superpowers/plans/`。

## Flags

<ParamField query="--force" type="boolean">
  跳过所有确认提示，直接执行卸载。适用于脚本化场景。
</ParamField>

<ParamField query="--scope" type="string">
  限制卸载范围。可接受值：`project`（当前目录）或 `global`（home 目录）。不设置时，会扫描两个 scopes。
</ParamField>

<ParamField query="--json" type="boolean">
  抑制交互式输出，输出 structured JSON result。
</ParamField>

## 示例

### 交互式卸载

```bash
comet uninstall
```

```

  ◯ Claude Code (project)
  ◯ Cursor (global)

? Select targets to uninstall: (Use space to select)
  ◉ Claude Code
  ◯ Cursor

Removing Comet components from Claude Code (project)...
  Skills: 8 removed
  Rules: 2 removed
  Hooks: 1 removed
  Working directories: removed

Done. 1 target processed.
```

### JSON Output

```bash
comet uninstall --json
```

<Note>
  `comet uninstall` 只会移除 Comet 分发的文件。你自己创建的 skills、项目代码和配置文件不会被影响。如果需要重新安装，运行 [`comet init`](/zh/cli/init)。
</Note>
