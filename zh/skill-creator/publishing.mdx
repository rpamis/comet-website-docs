Comet Any 本地验收通过后，先展示完整包导出和正式安装预览。你确认当前预览，SDK 才写入目标；应用不需要自己的安装脚本。

## 安装前看什么

| 预览内容    | 需要核对的事情                                     |
| ----------- | -------------------------------------------------- |
| 完整包      | 应用身份、版本、入口、模块与固定依赖               |
| 导出目录    | 应用包实际保存在哪里                               |
| 平台入口    | 本项目或用户目录会安装哪些 Skill                   |
| Rule / Hook | 写入的共享入口、平台支持和需要激活的配置           |
| 冲突与能力  | 现有文件是否冲突，宿主是否具备加载、交接和执行能力 |
| 证据        | 本地验收、模型 Eval 和宿主验证各自的结果           |

平台入口与完整包导出目录分开管理。不要只复制入口 `SKILL.md` 就认为整个应用及其依赖已经安装。

## 分发到其他平台

在需要安装的项目中运行：

```bash
comet application distribute ./weekly-report/application.json --project . --platform codex --preview --json
```

阅读本次预览并取得确认后，使用它返回的确认摘要：

```bash
comet application distribute ./weekly-report/application.json --project . --platform codex --confirmation-hash <本次预览确认摘要> --json
```

使用 `--platform all` 选择已登记的平台，或重复 `--platform` 选择多个平台。用户级安装使用 `--scope user`。平台能力以预览为准，入口安装成功不代表所有宿主能力都已经激活。

## 升级与卸载

升级时添加 `--upgrade` 并重新确认当前预览。SDK 更新平台入口，保留活动 Run 需要的旧版本。

卸载默认先预览。可以用 `--platform` 只移除所选入口，确认后执行；选择性卸载不会连带删除共享 Rule/Hook、依赖和仍需保留的版本。

```bash
comet application uninstall weekly-report --project . --platform codex --json
```

## 安装中断

部分写入或结果未知时，先核对原动作与目标文件，再沿原 Run 恢复。文件或配置漂移后，原预览批准不能继续使用。

命令参数见 [comet application](/zh/cli/application)。生成后的实际运行记录和证据可在 [Dashboard](/zh/dashboard/overview) 的 Comet Any 页面查看。
