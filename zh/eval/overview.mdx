Comet 的评估系统是一个基于 Python pytest 的基准测试框架，用于验证 Skill 包的质量、正确性和可靠性。

## 两条评估路径

Comet 提供两种评估方式：

<CardGroup cols={2}>
  <Card title="comet eval" icon="flask" href="/zh/eval/harness">
    **共享评估框架** — 评估 Skill 包或 eval manifest。用于验证 Skill 是否达到产品质量。
  </Card>
  <Card title="comet skill eval" icon="gauge" href="/zh/eval/runtime">
    **运行时评估** — 评估特定 Engine Run 的运行时检查。用于验证执行过程中的状态和产物。
  </Card>
</CardGroup>

## 评估层次

| 层次 | 命令 | 用途 | 复杂度 |
|---|---|---|---|
| 运行时评估 | `comet skill eval` | 验证 Run 状态和产物 | 轻量 |
| 快速冒烟 | `comet eval run --quick` | 验证基本功能 | 低 |
| 完整基准 | `comet eval run` | 全面质量验证 | 高 |

## 何时使用

### 运行时评估 (`comet skill eval`)

- 在 Skill Run 执行过程中检查进度
- 验证特定步骤是否完成
- 检查产物是否生成

### 共享评估框架 (`comet eval`)

- 发布前验证 Skill 质量
- 比较不同版本的 Skill
- 评估任意本地 Skill
- 生成结构化评估报告

## 评估任务

评估框架内置多种评估任务：

| 任务 | 难度 | 说明 |
|---|---|---|
| `generic-skill-smoke` | 简单 | 任意 Skill 的冒烟测试，期望 `result.md` 产物 |
| `authoring-skill-smoke` | 简单 | 生成的 Comet-native Skill 包的冒烟测试 |
| `comet-full-workflow` | 困难 | 完整的 open→design→build→verify→archive 流程测试 |
| `comet-fix-median` | 中等 | Bug 修复工作流测试 |
| `comet-refactor-counter` | 中等 | 重构工作流测试 |
| `comet-perf-dedupe` | 中等 | 性能优化工作流测试 |
| `comet-api-cache-ttl` | 中等 | API 缓存工作流测试 |
| `comet-robust-config` | 中等 | 配置管理工作流测试 |

## 环境要求

运行评估需要：

- Python 3.11+
- `uv` 或等效的 Python 环境管理器
- Docker
- Claude Code CLI（`claude`）
- `ANTHROPIC_API_KEY` 环境变量

## 快速开始

### 安装依赖

```bash
cd eval
uv sync
```

### 运行快速冒烟测试

```bash
comet eval run --skill-path ./my-skill --skill-name my-skill --quick
```

### 运行完整评估

```bash
comet eval run --manifest ./comet/eval.yaml
```

### 生成 HTML 报告

```bash
comet eval run --manifest ./comet/eval.yaml --html
```
