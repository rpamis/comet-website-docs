## What's Changed [0.1.4] - 2026-05-15

### Fixed

- **Superpowers redundant project-level install**: `comet init` 现在会在安装 Superpowers 前先检查用户所选所有平台的全局目录（`~/{platform}/skills/`）。如果某个所选平台已全局安装 Superpowers，则跳过该平台的项目级安装
- **Unwanted `.agents/` directory creation**: `comet init` 现在会向 `skills add` 传递 `--agent` 标志，只针对用户选择的平台。这避免了 skills CLI 自动检测并安装到所有平台，从而不再创建多余的 `.agents/` 目录
- **OpenSpec global detection**: 对 OpenSpec 检测应用相同的全局目录回退逻辑，避免在所选平台已全局存在时重复安装 OpenSpec

### Changed

- `hasSkills()` 接受 `selectedPlatforms` 参数，将全局检测范围限定为用户选择的平台
- `installSuperpowersForPlatform()` 被 `installSuperpowersForPlatforms()` 替代，后者接受平台 ID 并通过 `SKILLS_AGENT_MAP` 映射到 skills CLI 的 agent 名称
