## What's Changed [0.1.3] - 2026-05-15

### Added

- **State File Separation**: Comet 工作流状态现在存储在独立的 `.comet.yaml` 文件中，不再放在 `.openspec.yaml` 的子树里
- **Three-Layer Reliability Defense**:
  - 所有阶段的入口校验，带 `[HARD STOP]` 诊断
  - 所有状态变更采用先写入后校验的模式
  - schema 校验脚本（`comet-yaml-validate.sh`），支持字段、枚举和路径校验
- **Path Traversal Protection**: 对 change 名称做输入校验，防止目录穿越攻击
- **Guard Script Integration**: 在阶段转换时自动进行 schema 校验

### Changed

- 更新全部 9 个 Comet Skill，使用 `.comet.yaml` 替代 `.openspec.yaml` 的 `comet:` 子树
- 改进错误信息，使用具体字段值替代通用占位符
- 完善项目结构文档

### Security

- 修复了通过未校验的 change 名称输入导致的路径穿越漏洞
- schema 校验现在能在入口处捕获拼写错误和无效的枚举值
