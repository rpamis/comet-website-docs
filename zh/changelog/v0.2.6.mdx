## What's Changed [0.2.6] - 2026-05-23

### Added

- **构建决策强制校验**: 构建守卫和 `comet-state.sh transition build-complete` 现在要求 `isolation` 和 `build_mode` 才能从 build 推进到 verify
- **直接模式覆盖**: 完整工作流必须先设置 `direct_override: true` 才能使用 `build_mode: direct`；hotfix/tweak 默认仍然允许
- **可配置的守卫命令**: 守卫脚本现在会先从变更的 `.comet.yaml` 或仓库根目录的 Comet 配置中读取 `build_command` 和 `verify_command`，找不到时再回退到自动检测的构建命令
- **归档差异预览**: 归档同步在覆盖现有主规格（当其与 delta 规格不同时）之前，会先打印统一 diff
- **跨平台脚本冒烟 CI**: 新增 Ubuntu、macOS 和 Windows 的冒烟测试覆盖，针对 Comet shell 脚本和可移植 shell 测试
- **Shell 换行符策略**: 新增 `.gitattributes` 规则，保持 shell 和 Bats 脚本使用 LF 换行符

### Changed

- **守卫失败输出**: 守卫检查现在会保留并打印命令失败输出，并附带可操作的 `Next:` 提示，用于缺失构建决策和未完成任务
- **命令处理**: 项目命令通过 `bash -lc` 运行，Maven 在适当时使用 `mvnw` 或 `mvn.cmd`，shell 测试辅助工具会处理 Windows Git Bash 路径
- **归档步骤计数**: Dry-run、delta 同步、标注、移动和归档状态步骤现在统计实际执行的步骤，不再对重复操作重复计数
- **英文文档和 Skill**: 将英文 README 和 Comet Skill 文本与中文的构建决策、命令配置和归档行为描述保持同步

### Fixed

- **macOS shell 脚本状态更新**: 将 `comet-state.sh` 中仅 GNU 支持的 `sed -i` 写入替换为可移植的临时文件更新方式，修复了 macOS 在 `scale`、`transition` 和 YAML 字段更新时的 CI 失败
- **pipefail 下可选字段读取**: 守卫和状态脚本现在在 `set -euo pipefail` 下对缺失的可选 YAML 字段具有容错性，不会提前退出
- **Bash 检测回退**: shell 测试辅助工具现在能处理 `bash` 探测失败的情况，不会因 `spawnSync` 输出为空而崩溃
- **配置命令持久化**: `comet-state.sh set` 现在会转义 sed 替换元字符，确保包含 `&`、`|` 或反斜杠的命令值得以保留
- **可选 schema 字段**: YAML 校验现在能识别 `direct_override`、`build_command` 和 `verify_command`
- **带引号的 YAML 值**: 状态、守卫和校验脚本现在仅去除包裹引号，而非删除值中的所有引号字符

### Tests

- 新增测试覆盖：缺失构建决策、直接模式覆盖的阻断与允许、配置的构建/验证命令、命令元字符保留、未完成任务补救输出、归档步骤计数、跨平台路径处理、BSD/GNU sed 可移植性、pipefail 下可选 YAML 字段读取以及 bash 探测失败处理
