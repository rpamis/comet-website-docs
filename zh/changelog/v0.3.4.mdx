## What's Changed [0.3.4] - 2026-05-29

### Changed

- **Command execution security**: 将 OpenSpec 和 Superpowers 安装路径中的所有命令执行从带 shell 解释的 `spawn` 重构为 `execFileSync`，消除了 shell 注入风险面并提升了跨平台可靠性 (#88bf487)

### Fixed

- **OpenSpec global install path for OpenCode**: `comet init --scope global` 现在会将 OpenSpec skills 从硬编码的 `~/.opencode/` 目录迁移到 OpenCode 实际读取的 `~/.config/opencode/` 目录，并在源路径与目标路径相同时加入自删除守卫 (#46, @gleami)
- **Windows command execution**: 在 Windows 上为 `execFileSync` 调用添加了 `shell` 选项，使命令 shim（.cmd）能够正确解析
- **Doctor `.comet.yaml` validation**: `comet doctor` 现在会校验顶层键，而不是静默接受未知键；同时除 ENOENT 之外的 `readDir` 错误不再被吞掉 (@felamin)
- **CI JSON parsing**: CI 工作流通过查找第一个 `{` 字符来解析命令输出，避免非 JSON 前缀行破坏 JSON 提取 (@yicochen)
- **CI warning output**: CI 现在仅在某一步骤实际失败时才统计并打印警告，减少了成功运行时的噪音 (@yicochen)
- **Spawn stdio noise**: 将非交互式 spawn 的 stdio 从 `inherit` 改为 `ignore`，使 OpenSpec/Superpowers 安装器不再向控制台打印无关的进度信息 (@yicochen)

### Tests

- 新增了对 OpenCode 全局 OpenSpec 路径迁移、自删除守卫和主目录 mock 的测试覆盖
- 新增了针对 `.comet.yaml` 顶层键校验以及非 ENOENT 的 `readDir` 错误传播的 doctor 测试
- 修复了基于 git 的测试 "uses plan base-ref to scale verification" 的超时问题

### Docs

- 改进了 README 的配置指引，提供更清晰的安装说明和可折叠的参考面板（中英文均更新） (@hepeng)
- 在 README 和 README-zh 中都新增了贡献者墙 (@Joechan11)
