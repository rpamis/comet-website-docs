## What's Changed [0.2.0] - 2026-05-18

Comet 0.2.0 是一次综合性优化版本：涵盖 Skill 可靠性、CLI 完整性以及工程质量。

### Skill Reliability

- **SKILL.md 双区结构**: 全部 8 个 Skill 拆分为"决策核心"（阶段检测、升级条件、错误处理）和"参考附录"（字段参考、脚本、最佳实践）两部分
- **量化升级条件**: Hotfix/tweak 现在定义了升级到完整工作流的明确阈值（文件数量、跨模块协调、架构变更等）
- **脚本位置缓存**: 所有 Skill 使用 `${VAR:-$(find ...)}` 环境变量缓存模式，避免重复调用 `find`
- **`manifest.json` 修复**: 补充了缺失的 `comet-state.sh` 和 `comet-archive.sh` 条目
- **`comet-state.sh init` 修复**: 现在会将 `workflow` 字段写入 `.comet.yaml`，修复了此前 `check design` 始终失败的问题

### CLI Commands

- **`comet status`**: 显示当前活跃变更的阶段、任务进度、工作流模式、设计文档和计划（支持 `--json`）
- **`comet doctor`**: 诊断安装健康状况——包括 OpenSpec CLI、工作目录、各平台的 Skill 完整性、脚本是否存在、`.comet.yaml` 有效性（支持 `--json`）
- **`comet update`**: 将 comet skill 文件更新为 npm 包中的最新版本（支持 `--language`、`--scope`）
- **所有命令支持 `--json`**: `init`、`status`、`doctor`、`update` 均可输出结构化结果

### Engineering

- **测试套件**: 54 个单元测试（5 个套件），语句覆盖率 93.8% / 函数覆盖率 100%；26 个 bats shell 测试
- **GitHub Actions CI**: 在推送/PR 时执行构建 + lint + 格式化 + 测试（Node 18/20/22）+ shellcheck + bats
- **ESLint + Prettier**: 代码质量工具，通过 `pnpm lint` / `pnpm format` 调用
- **代码组织**: 将单体式的 `init.ts`（620 行）拆分为 5 个聚焦的核心模块 + 4 个命令模块
- **命令注入加固**: 在构造 shell 命令前对平台/工具 ID 进行校验
- **逐文件错误处理**: 复制循环在单个文件失败时继续执行，不会中断
