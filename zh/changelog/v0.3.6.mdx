## What's Changed [0.3.6] - 2026-06-02

### Added

- **Plan-ready build pause state**: 新增 `build_pause` 作为构建阶段的专用暂停标记，使 Comet 可以在生成计划后停下，而不会将该暂停与实际执行方式混淆。
- **Plan-ready pause design**: 新增了一份关于模型切换暂停工作流的设计文档，涵盖恢复行为、过期暂停处理和计划缺失的补救措施。

### Changed

- **Build recovery routing**: `/comet` 和 `/comet-build` 现在能识别 `build_pause: plan-ready`，复用已有计划，并从工作区隔离和执行方式选择处恢复，而不再重新生成计划。
- **Bilingual workflow documentation**: 中英文 Comet skills 现在都描述了 plan-ready 暂停点，明确 `build_pause` 不是 `build_mode`，并在两份 README 中记录了相同的状态字段。

### Fixed

- **GitHub Copilot Superpowers skill names**: Comet skills 现在调用由 GitHub Copilot skills 路径安装的 Superpowers 裸 skill 名，避免因无法解析的 `superpowers:*` 别名导致工作流阻塞。
- **Windows bash resolution**: Comet 现在通过 `COMET_BASH` 解析可用的 bash 可执行文件，拒绝 Windows WSL 启动器路径，并将解析出的可执行文件用于嵌套脚本调用，使守卫、交接和归档流程不会回退到损坏的 PATH `bash`。
- **Shell test runner bash resolution**: `run-bats.js` 现在通过 `COMET_TEST_BASH`、`COMET_BASH`、PATH 或 Git Bash 默认值来解析可用的 bash，避免从 Node 运行 shell 测试时使用损坏的 Windows WSL 启动器。
- **Schema validation fatal output**: 守卫校验现在会在打印校验器诊断信息后保留最终致命的 schema 校验消息，使无效的 `.comet.yaml` 失败更易于识别。

### Tests

- **Superpowers skill invocation regression**: 新增测试覆盖，确保随附的 Comet skill 文本不引用带插件前缀的 Superpowers 别名。
- **Comet bash execution regression**: 新增测试覆盖，包括嵌套脚本调用、随附命令示例和 shell 测试运行器，确保 Comet 使用解析后的 bash 路径而非原始 PATH `bash`。
- **Plan-ready pause regression**: 新增 shell 脚本测试覆盖，包括 `build_pause` 初始化、schema 校验、状态更新和构建恢复输出。
- **README state-field regression**: 新增 README 测试覆盖，确保 `build_pause` 出现在中英文文档的示例和字段说明中。
