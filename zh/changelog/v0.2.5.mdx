## What's Changed [0.2.5] - 2026-05-22

### Added

- **PR 标题 lint 工作流**: 新增 GitHub Actions 校验，要求语义化 PR 标题并使用 Comet 专用范围（`cli`、`commands`、`core`、`skills`、`assets`、`scripts`、`docs`、`ci`、`deps`、`release`）
- **结构化 JSON 输出**: `comet init --json` 和 `comet update --json` 现在输出机器可读的结果，而非混合的人类日志
- **`doctor --scope`**: `comet doctor` 可诊断 `auto`、`project` 或 `global` 范围，`auto` 会同时检查项目级和全局级安装
- **下一步状态提示**: `comet status` 现在会在文本和 JSON 输出中提示下一个工作流命令（`/comet-open`、`/comet-design`、`/comet-build`、`/comet-verify`、`/comet-archive`）
- **README 资源守卫**: 新增测试和 prepublish 校验，确保 README 中的图片使用 npm 友好的绝对 URL

### Changed

- **`comet update` 保留已安装上下文**: update 现在会检测项目级/全局级范围内已有的 Comet Skill 目标，保留已安装范围，检测中文还是英文 Skill，并仅更新已安装 Comet Skill 的平台
- **`comet update` 自更新 npm 包**: update 现在在刷新已安装 Skill 之前，会打印并运行与检测到的包范围对应的 npm 更新命令
- **更友好的 update 输出**: update 会记录 npm 命令、各目标的 Skill 复制命令、最终的 npm 状态、已更新目标数、范围和语言摘要
- **Init 覆盖流程**: 交互式 `comet init` 现在会在同一平台检测到多个已有组件时，提供批量覆盖/跳过选项
- **CLI 选项校验**: `update --language`、`update --scope` 和 `doctor --scope` 现在通过 Commander 的 choices 校验接受的值
- **README CLI 文档**: 更新了中英文 README 命令章节，记录了 JSON 输出、doctor 范围、update 行为、status 下一步提示以及 init 覆盖行为
- **CONTRIBUTING 链接**: 在中英文 README 的开发章节中添加了贡献指南引用

### Fixed

- **Doctor 误报**: `comet doctor` 现在能识别当前的 `.comet.yaml` 字段，包括 `verification_report` 和 `branch_status`
- **npm README 图片**: README 图片现在使用绝对的 GitHub URL，以便包页面能正确渲染

### Tests

- 新增测试覆盖：update 语言/范围检测、JSON 输出、友好的命令显示、status 下一步提示、doctor 当前状态校验、README 图片 URL、init 批量覆盖选择以及 PR 标题工作流配置
