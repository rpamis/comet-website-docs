## What's Changed [0.3.2] - 2026-05-27

### Added

- **Script discovery helper**: 新增 `comet-env.sh`，通过从其自身目录 source 同级脚本来集中化脚本路径解析，取代所有中英文 Skill 中分散的 `COMET_SEARCH_ROOTS` 查找逻辑。
- **OpenCode global config directory**: OpenCode 平台现在为全局安装支持独立的 `globalSkillsDir`（`.config/opencode`），使项目级和用户级 Skill 保持区分。
- **Command error diagnostics**: 新增 `command-error.ts` 模块，用于提取和清理失败 shell 命令的 stderr/stdout，被 OpenSpec 和 Superpowers 安装路径共同使用，以呈现可操作的失败详情。

### Changed

- **Build decision-point wording**: 强化了 build Skill 中工作区隔离和执行方式选择的措辞，使 agent 不能基于推荐规则替用户做出选择。
- **Hotfix/Tweak upgrade wording**: 重新表述了 hotfix 和 tweak Skill 中的升级条件和验证失败暂停要求，以获得更清晰的阻断语义。
- **Comet user decision numbering**: 修复了中文 comet Skill 中用户决策点列表的编号顺序错乱问题。

### Fixed

- **OpenSpec workflow installation**: `comet init` 现在使用 `--profile custom` 和一个启用所有工作流（`propose`、`explore`、`new`、`continue`、`apply`、`ff`、`sync`、`archive`、`bulk-archive`、`verify`、`onboard`）的临时配置来运行 OpenSpec，确保 Comet 安装的不仅仅是默认的核心工作流集合。
- **OpenCode slash commands**: `comet init` 现在生成 OpenCode 命令文件（`commands/*.md`），保留 `/comet*` 命令名的同时嵌入对应的 Comet 工作流内容，使 OpenCode 用户可以直接调用 `/comet`、`/comet-open` 等。
- **Lingma Superpowers path**: `comet init` 现在让 Lingma 避开不受支持的 `skills --agent lingma` 路径，并将暂存的 Superpowers Skill 复制到 `.lingma/skills`，防止整个外部安装批次失败，同时保留 Lingma 预期的目录布局。
- **Lingma global directory**: Lingma 的全局 Skill 目录明确为 `.lingma`，用户级安装匹配 `~/.lingma/skills/{skill-name}/SKILL.md`，项目安装匹配 `.lingma/skills/{skill-name}/SKILL.md`。
- **Script discovery safety**: `comet-env.sh` 被 source 时不再改变调用者的 shell 选项，在捆绑脚本缺失时返回失败，并避免 ShellCheck 的 unreachable-command 诊断。
- **comet-state.sh field whitelist**: 将 `created_at` 和 `base_ref` 添加到 `cmd_set` 允许字段列表中，使验证与 `.comet.yaml` 初始化期间已写入的字段保持一致。

### Tests

- **Script discovery coverage**: 添加了验证 `comet-env.sh` 导出所有捆绑脚本路径以及没有 Skill 文件内联 `COMET_SEARCH_ROOTS` 的测试。
- **Script discovery safety**: 为 source 时保留 shell 选项和可展开的 `$HOME` Skill 目录 glob 添加了回归测试覆盖。
- **OpenCode Comet detection**: 为 OpenCode 在报告 Comet 已安装之前需要同时具备 Skill 目录和匹配的命令文件添加了测试。
- **OpenCode E2E init**: 为 OpenCode 项目和全局范围安装添加了端到端测试，包括命令文件生成。
- **OpenCode command content**: 添加了测试，验证 OpenCode 命令文件保留 Comet 命令名，并包含完整的所选语言工作流内容，而非一个轻量的 Skill 委派桩。
- **English workflow safeguards**: 添加了与现有中文工作流决策点需求匹配的对等性测试。
- **OpenSpec profile and diagnostics**: 为自定义 profile 创建、`--profile custom` 标志以及安装失败时打印 stderr/stdout 详情添加了测试。
- **Lingma Superpowers fallback**: 添加了回归测试覆盖，验证 Lingma 被排除在不支持的 skills CLI agent 列表之外，并在将 Skill 复制到 `.lingma` 之前使用暂存安装。
- **Lingma global install path**: 为 `comet init --scope global` 将 Lingma Comet Skill 安装到用户 `.lingma/skills` 目录下添加了回归测试覆盖。
