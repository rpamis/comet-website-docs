## What's Changed [0.3.5] - 2026-05-29

### Added

- **Context compaction recovery (`--recover`)**: `comet-state check <name> <phase> --recover` 输出结构化的恢复上下文，包括阶段状态、字段进度、任务数量和恢复操作，用于 agent 的上下文压缩，以便快速定位断点并恢复操作。
- **Red Flags Anti-Rationalization List**: 在主调度 skill 中新增 5 条红旗警告（替用户做决定、跳过确认、替换历史偏好、无异议地附和、未验证即放行），帮助 agent 识别自身的越权倾向。
- **Uncertainty Degradation Principles**: 在 verify skill 中新增 SUGGESTION > WARNING > CRITICAL 降级规则。只有构建失败、测试失败和安全问题会被标记为 CRITICAL；模棱两可的问题必须降级。
- **Anti-Automatic Selection Guardian**: 在 open skill 中新增命名与范围的防自动选择规则。名称变更必须由用户指定或通过 AskUserQuestion 确认；范围不得任意扩大或缩小。
- **File Existence Verification**: 在进入用户确认前，open skill 会校验 proposal/design/tasks 文件不为空，防止空文件跳过检查。
- **Idempotency Description**: 为所有 skill 阶段（open/design/build/verify）新增幂等性说明，明确哪些操作可以安全重试、哪些字段在跳过前需要确认。

### Changed

- **AskUserQuestion Tool Clarification**: 全部 7 个决策阻塞点（open 确认、头脑风暴确认、构建工作流、verify 失败决策、spec 偏移处理、分支处理、升级条件）统一要求使用 AskUserQuestion 工具；禁止使用纯文本提示。
- **Decision Points Expanded from 6 to 7**: open 阶段的 proposal/design/tasks 审阅确认现在成为第一个决策点。
- **Spec Drift Single-Choice Question Format**: verify 阶段的 spec 偏移处理改为 AskUserQuestion 单选题（A/B/C 三选一），不再有隐式默认选项。
- **Completely synchronized Chinese and English skills**: 7 个中文 skill 和 7 个英文 skill 的内容、结构和选项格式已完全对齐。

### Fixed

- **Crash due to unbound variables in `set -u`**: 当 `comet-state check --recover` 在构建阶段缺少 `tasks.md` 时，`pending` 变量未声明会导致脚本直接退出；现已通过将 `local` 声明前移并在恢复操作链中增加显式分支 `tasks.md MISSING` 修复。
- **Path truncation risk**: `field_status` 对 `design_doc` 使用 `${var%% *}` 可能截断含空格的路径；已改为 `${var% }` 仅去除末尾空格。
- **Inconsistent reading style for optional fields**: `direct_override` 使用 `|| echo ""`，而其他可选字段使用 `|| true`；现已统一为 `|| true`，与 `cmd_scale` 保持一致。

### Tests

- 新增 8 个 `check --recover` 与边界测试用例，覆盖 open/build/verify/design/archive 五个阶段，以及缺少 tasks.md 和全部任务完成等边界场景。
- 测试总数从 34 个增加到 42 个，全部通过。
