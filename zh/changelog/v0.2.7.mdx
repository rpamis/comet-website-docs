## What's Changed [0.2.7] - 2026-05-24

### Fixed

- **OpenSpec 全局初始化**: `comet init` 的全局范围现在会将主目录作为 OpenSpec 的初始化目标传入，而不是使用不支持的 `openspec init --global` 标志
- **跨平台路径引用**: OpenSpec 初始化目标针对 Windows、macOS 和 Linux 路径进行了 shell 引号处理，包括含空格的主目录
- **安装器参数引用**: OpenSpec 的 `--tools` 值和 Superpowers 的 `--agent` 值现在都进行了 shell 引号处理，Windows 下 OpenSpec 路径在闭合引号前保留尾部反斜杠
- **Superpowers 多平台安装**: Superpowers 安装现在会传入重复的 `--agent` 标志，而非逗号分隔的 agent 列表，与 `skills` CLI 行为一致
- **Superpowers agent 映射**: 将 Comet 平台映射更新为有效的 `skills` CLI agent ID，不支持的平台专用 ID 会回退到 `universal`

### Tests

- 新增回归测试覆盖 Windows、macOS 和 Linux 下的 OpenSpec 全局初始化命令构造
- 新增回归测试覆盖 OpenSpec Windows 尾部反斜杠引用和带引号的安装器参数
- 新增 Superpowers 覆盖测试：有效的 `skills` CLI agent 映射和多 agent 参数格式
- 在隔离的临时目录中，对所有 28 个支持平台的项目级和全局级初始化输出进行了冒烟测试
