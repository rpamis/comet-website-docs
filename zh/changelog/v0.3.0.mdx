## What's Changed [0.3.0] - 2026-05-25

### Added

- **Dirty worktree recovery protocol**: 新增共享的中英文 `comet/reference/dirty-worktree.md` 参考文档，使 agent 在恢复时能够一致地保护、检查并归属用户或混合来源的工作树变更。

### Changed

- **Comet resume behavior**: 更新了 `/comet`、build、verify、hotfix 和 tweak Skill，使中断期间手动编辑的代码被视为代码证据，而非自动状态转换；agent 在继续或推进守卫之前必须对脏工作树变更进行归属。

### Fixed

- **Reference skill installation**: 将脏工作树参考文件添加到 Comet 清单中，使已安装的中英文 Skill 集能够解析 `comet/reference/dirty-worktree.md`。
