## What's Changed [0.2.3] - 2026-05-19

### Added

- **"Why Comet" 章节**: README 现在解释了 Comet 的设计理念——它如何将 OpenSpec 的 WHAT 管理与 Superpowers 的 HOW 执行结合为统一的 5 阶段流水线
- **"Screenshots" 章节**: 新增三张截图，展示平台选择、初始化以及 Skill 实际执行的过程
- **"What You'll Learn" 章节**: 新增章节，展示 Comet 作为稳定嵌套 Skill 触发和多阶段自动流转模式的参考实现
- **State Management YAML 示例**: 扩展了文档，增加了完整的 `.comet.yaml` 字段示例，展示所有关键配置值

### Changed

- **comet-build Skill 描述**: 明确了执行模式（子 agent 还是 executing-plans）由用户根据任务复杂度选择，而非始终由子 agent 驱动
- **增强 State Management 文档**: 增加了对所有状态和阶段如何通过脚本更新、并在阶段推进前进行完成性校验的说明
