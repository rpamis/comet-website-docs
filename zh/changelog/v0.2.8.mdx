## What's Changed [0.2.8] - 2026-05-24

### Added

- **设计交接脚本**: 新增 `comet-handoff.sh`，从 OpenSpec 制品生成确定性、可溯源的上下文包（精简或完整模式）至 `.comet/handoff/`，并在 `.comet.yaml` 中记录 `handoff_context` 和 `handoff_hash`
- **交接守卫检查**: 设计阶段守卫现在会校验交接上下文是否存在、哈希新鲜度（检测交接后 OpenSpec 的变更）、markdown 可追溯性标记，以及设计文档 frontmatter 字段（`comet_change`、`role: technical-design`、`canonical_spec: openspec`）
- **`handoff_context` 和 `handoff_hash` 字段**: 新增 `.comet.yaml` 字段，用于跟踪脚本生成的交接包，并带有 schema 校验（路径存在性、sha256 十六进制摘要格式）
- **`comet init --scope`**: 新增 `--scope <global|project>` CLI 标志，用于非交互式范围选择
- **CI init E2E 作业**: GitHub Actions 现在会在 Ubuntu、macOS 和 Windows 上运行真实的 `comet init`，验证 Comet Skill、Superpowers、OpenSpec 和工作目录是否落在正确的文件系统位置（项目级和全局级均覆盖）

### Changed

- **中文 Skill 文档更新**: `comet-design/SKILL.md` 和 `comet/SKILL.md` 现在记录了交接流程，用脚本生成的上下文包替代了 agent 自行撰写的摘要
- **JSON 生成使用进程替换**: `comet-handoff.sh` 中的 `write_json_context` 使用 `< <(source_files)` 替代管道子 shell，修复了变量作用域问题
- **错误信息格式化**: `comet-state.sh` 中未知字段的错误信息从单行 270+ 字符拆分为多行，提升可读性
- **CLAUDE.md 和 AGENTS.md**: 新增了项目级说明，涵盖测试命令、shell 脚本约定、脚本依赖图、`.comet.yaml` 状态机同步规则以及 changelog 格式

### Fixed

- **YAML 和 frontmatter 解析**: Comet 脚本现在会忽略 `.comet.yaml` 字段值中未加引号的尾部注释，并接受 UTF-8 BOM 或前导空行之后的设计文档 frontmatter，避免误判守卫和交接失败
- **Init E2E 安装检查**: CI 现在会验证每个支持平台目录下 Comet 拥有的 Skill 制品，并从 `comet init --json` 检查 OpenSpec/Superpowers 安装器状态（项目级和全局级安装均覆盖），避免因外部 CLI 专用目录布局导致的误判失败
- **Windows 全局 init E2E 主目录**: CI 现在会在 Windows 上全局范围 init 检查时同时设置 `USERPROFILE` 和 `HOME`，与 Node 的 `os.homedir()` 解析方式保持一致，避免误判 Skill 缺失
- **README 状态文档**: README 示例现在展示了准确的 `.comet.yaml` 构建状态默认值、验证证据时机、交接字段以及仅项目级创建工作目录的行为
- **Windows Superpowers init 超时**: Superpowers 外部安装器超时时间已增加，以容忍较慢的 Windows `npx skills add` 运行，减少 init E2E 的偶发失败

### Tests

- 新增测试覆盖 `--full` 交接模式、缺失 OpenSpec 制品拒绝、交接后哈希不匹配检测以及设计文档 frontmatter 校验
- 新增 `comet init` E2E 测试，覆盖项目级安装、全局级安装、使用 `--yes` 跳过已存在项、使用 `--overwrite` 覆盖以及多平台检测
- 新增回归测试覆盖 `.comet.yaml` 尾部注释以及带 UTF-8 BOM 或前导空行的设计文档 frontmatter
- 新增 CI 工作流回归测试，覆盖 Comet 拥有文件和外部 OpenSpec/Superpowers 安装器状态的项目级与全局级安装检查
- 新增 CI 工作流回归测试，覆盖使用临时 `USERPROFILE` 主目录的 Windows 全局 init
- 新增回归测试覆盖 init 使用的更长 Superpowers 安装器超时时间
