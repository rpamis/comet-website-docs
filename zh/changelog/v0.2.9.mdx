## What's Changed [0.2.9] - 2026-05-24

### Changed

- **Antigravity Skill 路径**: 更新了平台处理方式，项目级安装使用 `.agents/skills`，而全局级安装使用 Antigravity 的 `.gemini/antigravity/skills` 位置，使 `init`、`doctor` 和 `update` 与 Antigravity 的目录模型保持一致
- **README 信息架构**: 重构了中英文 README 章节，将命令详情、平台列表、Skill 表、脚本表、`.comet.yaml` 字段和可靠性说明放入可折叠的参考面板中
- **Spec 生命周期文档**: 扩展了 README 中对 Comet Spec 生命周期管理的说明，包括 OpenSpec/Superpowers 制品关联、自动交接、状态更新、校验和归档同步
- **安全指南位置**: 将仓库维护安全说明从 README 移至 `CONTRIBUTING.md`，使 README 聚焦于面向用户的 Comet 概念和安装配置

### Fixed

- **Antigravity 全局安装**: 修复了 `comet init --scope global` 及相关健康检查，使 Antigravity 不再在项目风格的 `.agents` 目录下安装或搜索全局 Skill
- **缺失的 skills 目录**: 在扫描项目级和全局级 skills 目录之前新增了显式的存在性检查，确保在平台目录存在但缺少 `skills/` 时检测和更新逻辑依然稳健

### Tests

- **Antigravity 路径覆盖**: 新增回归测试覆盖 Antigravity 项目级/全局级 Skill 目录的检测和 init E2E 行为
- **README 结构覆盖**: 使用现有 README 测试套件验证了更新后的 README 命令和参考结构
