## What's Changed [0.2.2] - 2026-05-18

### Fixed

- **`comet init` 时 Ctrl+Z/Ctrl+C 崩溃**: 用 try/catch 包裹 inquirer 提示以处理 `ExitPromptError`，改为显示 `Cancelled.` 并干净退出，而不是打印原始堆栈跟踪
- **重复安装 Superpowers**: `comet init` 现在会检测通过 Claude Code 插件系统安装的 Superpowers（`~/.claude/plugins/cache/`），当 Superpowers 插件已存在时跳过冗余的 `npx skills add`
