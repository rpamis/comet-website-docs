Dashboard 为同一项目提供 Classic、Native、Comet Any、评估 Eval、个人记忆和项目知识工作区。侧边栏选择功能，顶部切换项目与语言；在 **设置 → 外观** 中选择亮色或暗色主题。

演示使用示例数据，不读取你的项目，不执行真实评估、安装或导出。选择已完成的应用，点击 **分发 / 导出**，可以查看配置选项；实际操作请启动本地 Dashboard。

## 启动本地 Dashboard

```bash
comet dashboard
```

服务绑定本机 `127.0.0.1`，默认端口 `4321`。使用 `--port <端口>` 指定端口，`--no-open` 只启动服务；完整选项见 [comet dashboard](/zh/cli/dashboard)。

## Classic 与 Native

选择变更，查看阶段、任务或验收进度、下一步建议、产物与 Git 摘要。工作区保持只读，推进、验证与归档仍由原工作流执行。

| 区域             | 用途                                                                |
| ---------------- | ------------------------------------------------------------------- |
| 统计卡片         | 切换活跃／归档，筛选执行或失败状态，打开任务、验收项或 Git 文件明细 |
| Changes Explorer | 按活跃、已归档、全部浏览，继续滚动加载其他变更                      |
| 详情             | 查看步骤、当前证据与下一步                                          |
| 状态侧栏         | 核对恢复、阻塞、工作区与 Git 信息                                   |

Native 状态统计覆盖全部活跃变更；归档总数单独显示。可归档状态仍在具体变更及下一步建议中显示。

已登记的 Git worktree 保留分支或目录归属。Supervisor 可以展开 child，并查看其验收、依赖和归档记录。某项读取失败会提供诊断与重试，不把失败当成零条记录。

## Comet Any

左侧选择创作目标或应用，中间查看当前固定版本和运行，右侧读取选中的步骤或执行记录。

**创作过程**展示方案、用户等待、本地验收、可选 Eval 和安装记录。**应用运行**展示安装应用后的实际任务。两者分开保存，同一版本的证据不会被其他版本替代。

可以查看步骤、执行尝试、产物及版本证据，打开已保存的子流程，或从证据进入关联 Eval。返回时保留原 Any 记录与阅读位置。

### 分发或导出已完成的应用

在本地 Dashboard 中选择已完成创作或已经固定的应用版本，点击 **分发 / 导出**。应用内容需要与该版本的记录一致；历史归档只供查看。

| 操作           | 配置与结果                                                                                                                                     |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 安装到 Agent   | 选择一个或多个 Comet 支持的 Agent 平台，以及项目级或用户级安装范围。可以填写自定义根目录；项目级默认使用当前项目，用户级留空使用当前用户目录。 |
| 升级已安装版本 | 勾选升级选项，预览安装变化；活动运行仍使用原先固定的版本。                                                                                     |
| 导出完整应用   | 填写尚不存在的目标目录，导出应用及固定的 Skill 依赖。运行记录不包含在导出包中。                                                                |

先点击 **预览**，核对版本、目标目录和将写入的文件，再确认安装或导出。修改平台、目录或其他选项后，需要重新预览；应用内容发生变化时，也需要重新确认。

用户决定在原 Agent 中获取并提交，Dashboard 不直接批准提案或推进 Run。创作说明见 [Comet Any](/zh/skill-creator/getting-started)。

## 评估 Eval

在 **新建评估** 中选择 Skill 或 SDK 应用目标，检查 Agent、模型、配置与预算，然后启动本地执行。详情显示实时阶段、当前用例、日志、报告和覆盖结果。

运行列表支持状态与基线筛选。你可以停止自己启动的执行、按原用例重试失败项、下载完整日志与报告，并管理适用的默认基线。

通用设置保存在 **设置 → Eval**，新运行复用默认配置，也可在本次运行中覆盖。没有执行的模型、路径或宿主保持未验证，见 [评估 SDK 应用](/zh/eval/applications)。

## 记忆与项目知识

页面分开显示当前记录、历史记录、检索来源与证据。管理操作会更新对应存储；项目记忆仍由 Agent 通过 `comet knowledge remember` 写入。

设置里的 **内置服务** 使用当前设备的 Comet 能力，**外部服务** 调用兼容的记忆或知识接口。接口地址旁的 **接口示例** 提供分别对应的请求与响应，Token 字段填写环境变量名，不能直接填写模型 API 地址。

## 运行性能

在 **可观测 → 运行性能** 中切换全部、Native 或 Classic，查看命令调用次数、成功率、一秒内成功响应比例、检查通过率和耗时 P50/P95。命令热点可按调用次数或累计耗时排序；结果分布保留非零退出码，慢记录支持打开详情。Git 调用与耗时在命令热点下展示，检查执行单独统计，复用已有检查不会计为新执行。

统计只使用当前工作区最近 7 天新采集的本地记录，最多保留 10,000 条，读取最近 5,000 条；截断时会显示提示。命令处理耗时不含 CLI 启动和模型思考时间，也不代表 Agent 完成整个任务的耗时。帮助、Hook 和 Dashboard 预览不参与采集，升级前的历史不会补造。

**Runtime 健康** 显示当前版本、当前环境的常驻处理请求、活动请求、内存与运行时长。状态读取不会启动进程，不计入命令次数，也不延长空闲生命周期；没有常驻进程时会明确显示。**SDK 执行质量** 读取当前项目至多 50 个 SDK 运行快照，展示已成功动作、首轮成功率、重试、等待确认与待核对动作。该快照不受 Native/Classic 筛选和 7 天窗口限制；首轮成功率的分母仅包含成功或失败的已结束动作，不可读记录与截断会单独提示。

## Change 执行链路

打开 **可观测 → Change 链路**，按 Native、Classic 或 Change 筛选执行记录。展开链路树查看动作、检查、上下文检索、等待与重试；点击节点查看起止时间、执行尝试、结果摘要和关联子运行。宽屏在右侧展示详情，窄屏使用弹窗。

时间条进入页面时展开，选中节点时显示高亮，运行中的节点持续显示流动提示；后台刷新不会重复播放入场动效，系统开启减少动效时停用这些动画。页面每 15 秒同步，刷新保留选中的记录和节点。已观测执行时长合并并行区间，并扣除显式等待；阶段条表示子节点的时间范围，包含间隔。历史快照保留结构与状态，没有采集的起止时间显示为未知，不补造模型调用、工具、Token 或费用。

计时记录按当前工作区隔离，保留最近 7 天、至多 10,000 个节点；列表读取最近 5,000 个节点，单条详情至多 2,000 个节点。历史快照每种工作流至多读取 50 个运行，部分数据不可读或截断时会提示。观测只读取已有记录，不批准决定或推进工作流。

## 产物、刷新与更新

产物可以预览 Markdown、JSON 和结构化记录；日志与报告保留对应的下载入口。页面会清洗不可信 HTML 内容。

刷新时保留所选记录、表单和阅读位置，首次读取显示结构化占位，后台更新保留已有内容。**设置 → 外观** 用预览卡片选择亮色或暗色主题，并提供字体大小调整；修改即时生效，在当前浏览器中跨项目保留。官网演示固定为亮色主题。主题和中英文切换保留导航状态，并尊重减少动效的系统偏好。

侧边栏显示运行版本和新版本提示。更新前确认项目范围，在弹窗中查看 CLI/npm 输出、失败与重试；关闭后可以再次打开查看进度。

项目选择器标记目录已经缺失的项目。确认 **从索引移除** 只清理索引，不删除文件或其他项目。
