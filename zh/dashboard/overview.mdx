Comet Dashboard 是本地运行的可视化研发控制台。在终端中运行长程任务时，Dashboard 为你提供实时可见的执行状态：查看 Classic 与 Native 变更进度、核验证据链、管理个人记忆与项目知识，以及追踪 Comet Any 创作流水和 Eval 评测表现。

<DashboardWebsiteDemo />

在线演示基于内置示例数据运行，不会读取你的本地项目，亦不触发真实的评测执行、安装或导出。若要在实际开发中使用，请在本地启动 Dashboard。

## 启动本地 Dashboard

在项目根目录运行：

```bash
comet dashboard
```

服务默认绑定在本机 `127.0.0.1:4321`，启动后会自动在默认浏览器中打开控制台。支持以下常用参数：

- `--port <端口>`：指定自定义端口（例如 `comet dashboard --port 5000`）；
- `--no-open`：仅启动后台 Web 服务，不自动弹出浏览器窗口。

完整参数与配置项详见 [comet dashboard 命令参考](/zh/cli/dashboard)。

<Tip>
  **推荐协作方式：双屏研发工作流**
  在日常编码中，推荐在左侧 IDE 或终端中输入 `/comet` 推进需求，在右侧屏幕挂载 Dashboard。当 Agent 进行多文件修改、跑自动化测试或触发 Verify 验收时，你可以在 Dashboard 上实时看到状态机流转与验收项逐条变绿，无需在繁复的终端日志中来回翻滚查找。
</Tip>

## Classic 与 Native 变更看板

变更看板实时同步本地磁盘上的 change 状态。你可以直观掌握每个任务当前处于哪个阶段、下一步操作建议、自动化检查结果与 Git 变更。

> Dashboard 保持只读安全设计：所有代码编写、推进确认、验证回退与最终归档均在 Agent 终端中由你掌控，Dashboard 不越权代为修改代码或强制推进状态。

| 看板区域 | 核心功能 |
| --- | --- |
| 统计指标卡片 | 切换活跃与已归档视图，筛选执行中或失败项，下钻查看任务、验收项或 Git 变更文件明细 |
| Changes 资源管理器 | 按活跃、已归档或全部维度浏览变更，支持平滑滚动加载历史记录 |
| 详情面板 | 实时查阅执行步骤、产物证据链及下一步操作指引 |
| 状态侧边栏 | 核验断点恢复检查点、阻塞因素、绑定工作区及 Git 分支详情 |

### 工作区与 Supervisor 协作追踪

- **Git worktree 映射**：准确显示每个变更绑定的独立分支与目录，避免误操作其他工作区。
- **Supervisor 树形视图**：对于复杂大型任务，看板可展开全部子任务（child），清晰展示子任务间的依赖拓扑、各自的独立验收结论与集成进度。
- **归档提示**：当变更的所有验收项均已通过且满足交付标准时，详情面板会高亮提示归档，并给出终端归档命令。

## 个人记忆与项目知识管理

Dashboard 为个人记忆和项目知识提供图形化卡片管理界面，摆脱纯命令行翻查的繁琐：

- **个人记忆（Personal Memory）**：分层展示核心画像（Core Profile）、协作偏好与经历记录。点击任一卡片可直接在线编辑、切换生效范围（全局或当前项目）、纠正偏差或一键遗忘，并查看最近 7 天的上下文命中率。
- **项目知识（Project Knowledge）**：结构化展示项目模型（目录架构、模块拓扑、技术事实）与项目策略（设计决策、稳定模式、工程规范）。
- **交互式检索模拟**：在项目知识页面输入模拟任务描述，系统会实时回显命中的知识卡片、排序分值以及具体的 `whyApplied` 触发理由，帮助你确认规则是否配置合理。
- **项目记忆**：集中管理由 Agent 在任务完成后记录的经验条目，支持全文搜索与清理维护。

## 评估 Eval

在 **新建评估** 中选取本地 Skill 或 SDK 应用，核对 Agent 平台、模型配置与测试预算后，即可一键发起本地评估执行。

- **实时执行看板**：详情面板实时同步评测阶段、正在执行的用例、终端日志与覆盖率数据。
- **报告与失败归因**：评测结束后自动生成可视化 HTML 报告，展示多维 Rubric 评分、`pass@k` 指标及具体的失败根因排查指引。
- **重跑与基线管理**：支持一键重跑失败用例、打包下载运行记录，并在 **设置 → Eval** 中集中维护默认评测基线。

详细评测操作请参考 [评估 SDK 应用](/zh/eval/applications) 与 [Eval 快速上手](/zh/eval/quickstart)。

## Comet Any 创作与运行追踪

在左侧选择创作目标或具体应用，即可在中间查看当前锁定的正式版本及运行流水，并在右侧查看详细步骤与产物。

- **创作全流程回溯**：完整记录需求分析、方案确认、本地验收、可选 Eval 评测与安装状态。
- **应用运行流水**：展示安装该应用后的真实任务流水与执行证据，二者严格隔离，互不干扰。
- **应用分发与导出**：在本地 Dashboard 选中已锁定的应用版本，点击 **分发 / 导出**：
  - **安装到 Agent 平台**：一键勾选多个支持的平台（如 Claude Code、Codex 等），选择项目级或全局生效；
  - **版本更新预览**：在线比对改动文件差异后再执行升级，正在运行中的任务不受影响；
  - **导出分发包**：一键导出包含锁定依赖的应用独立包，不夹带内部运行流水。

所有代码采纳与最终提交依然由你在 Agent 终端中确认。详细创作指引请参考 [Comet Any 快速上手](/zh/skill-creator/getting-started)。

## 运行性能与 Change 链路观测

### 运行性能仪表盘

进入 **可观测 → 运行性能**，查看本地任务的执行效率指标：

- **多维度筛选**：支持切换全部、Native 或 Classic 视图；支持筛选最近 1 小时、24 小时、7 天或全部时间跨度。
- **核心质量指标**：命令调用频次、整体成功率、1 秒内快速响应占比、检查通过率以及 P50 / P95 耗时。
- **热点榜单与异常分布**：按调用量或累计耗时排列高频命令，直观呈现非零退出码分布，慢执行记录支持一键展开排查明细。
- **Runtime 运行健康**：实时监控常驻服务状态、内存占用及已运行时间，采用非侵入式轻量查询，不额外拉起后台进程。

### Change 执行链路追踪

进入 **可观测 → Change 链路**，展开甘特树形结构查看任务全生命周期：

- **细粒度节点追踪**：涵盖动作执行、守卫检查、上下文检索、等待确认与自动重试。点击节点可查看起止时间戳、重试轮次与输出结果。
- **平滑甘特条**：执行中的节点显示呼吸动效，耗时统计自动合并并行区间并扣除人工等待耗时。
- **自动同步**：看板每 15 秒静默同步一次，刷新时完整保持当前选中的节点与树形展开状态，不闪烁跳动。

## 产物预览、主题与系统设置

- **全量产物预览**：支持完整预览 Markdown 文档、JSON 与各类结构化数据，提供全屏阅读模式与目录导航，日志与报告支持一键下载。
- **外观与主题切换**：在 **设置 → 外观** 中支持一键切换浅色或深色模式，支持平滑缩放界面字体大小，设置在当前浏览器内跨项目持久保存。
- **平滑更新与项目维护**：侧边栏底部提示当前版本与更新角标，支持在线更新 CLI；项目选择器会自动标记路径已失效的项目，支持一键安全清理索引，不误伤本地文件。
