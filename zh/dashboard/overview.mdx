Dashboard 为当前项目提供 Classic、Native、Comet Any、评估 Eval、个人记忆与项目知识等一站式可视化工作区。你可以通过侧边栏快速切换功能模块，顶部支持切换项目与多语言；在 **设置 → 外观** 中可按需选择浅色或深色主题。

<DashboardWebsiteDemo />

在线演示基于内置示例数据运行，不会读取你的本地项目，亦不触发真实的评测执行、安装或导出。选中已完成的应用后点击 **分发 / 导出**，可以预览对应的配置项；若要实际操作，请启动本地 Dashboard。

## 启动本地 Dashboard

```bash
comet dashboard
```

服务默认绑定在本机 `127.0.0.1:4321`。可通过 `--port <端口>` 指定自定义端口，通过 `--no-open` 仅启动服务而不自动弹出浏览器；完整参数详见 [comet dashboard 命令参考](/zh/cli/dashboard)。

## Classic 与 Native 双工作流看板

支持按变更（Change）查看当前阶段、任务排期、验收进展、下一步建议、产物清单与 Git 差异摘要。Dashboard 工作区严格保持只读，所有推进、验证与归档操作仍由原工作流在终端中执行。

| 区域 | 核心功能 |
| --- | --- |
| 统计指标卡片 | 切换活跃／已归档视图，筛选执行中或失败状态，下钻查看任务、验收项或 Git 变更文件明细 |
| Changes 资源管理器 | 支持按活跃、已归档或全部维度浏览变更，支持无限滚动平滑加载历史条目 |
| 详情面板 | 实时查阅执行步骤、物理产物证据链及下一步操作指引 |
| 状态侧边栏 | 核验断点恢复标识、阻塞因素、绑定工作区及 Git 分支详情 |

Native 状态统计完整覆盖所有活跃变更；已归档总数独立展示。若当前变更已达到归档要求，会在详情面板与建议操作中予以突出提醒。

已登记的 Git worktree 完整保留分支与目录的映射归属。Supervisor 视图可展开子变更（child），集中查阅其验收结果、上下游依赖与归档记录。当特定项读取异常时会明确提供诊断指引与重试入口，绝不将读取失败轻率显示为零条记录。

## Comet Any 创作与运行追踪

左侧选择创作目标或具体应用，中间查看当前固定的正式版本及其运行流水，右侧查看对应步骤的详细执行记录与产物。

- **创作过程**：完整回溯方案起草、用户确认等待、本地验收、可选 Eval 评测及安装记录。
- **应用运行**：展示安装应用后的真实任务流水。

二者严格隔离存储，同一版本的证据链绝不会被其他版本篡改或覆盖。

你可以在此细查具体步骤、尝试轮次、制品快照及版本证据，直接打开已保存的子流程，或从证据链一键跳转至关联的 Eval 评测。返回时会自动保留先前的 Any 浏览进度与视口位置。

### 分发与导出已就绪的应用

在本地 Dashboard 中选中已创作完成或已锁定的应用版本，点击 **分发 / 导出**。导出的应用内容会严格比对该版本的证据记录；历史归档仅供查阅。

| 分发方式 | 配置项与交付结果 |
| --- | --- |
| 安装到 Agent 平台 | 支持一键勾选多个 Comet 支持的 Agent 平台，并支持切换项目级或用户级全局生效范围。可自定义根目录；项目级默认写入当前工程，用户级默认写入当前用户主目录。 |
| 升级已有安装版本 | 勾选升级选项即可在线预览改动文件差异；当前正在运行中的任务仍继续使用原版本。 |
| 导出完整分发包 | 指定一个尚不存在的全新目录，一键导出应用主体及锁定的 Skill 依赖。导出的独立制品包中不夹带内部运行流水。 |

建议先点击 **预览** 仔细核对应用版本、目标物理路径及拟写入的文件清单，再行确认分发。若调整了目标平台、安装路径或其他配置，需重新预览；应用源码发生变动时同样需重新核验。

所有的代码采纳与最终提交均由开发者在原 Agent 客户端中自主确认，Dashboard 绝不越权代为批准或强推 Run 执行。创作指引详见 [Comet Any 快速上手](/zh/skill-creator/getting-started)。

## 评估 Eval

在 **新建评估** 中按需选取目标 Skill 或 SDK 应用，核对 Agent 平台、目标模型、测试配置与预算上限，即可一键拉起本地评估执行。详情面板会实时同步评测阶段、正在运行的用例、执行日志、产物报告及覆盖率统计。

评测运行列表支持按状态与基线灵活筛选。你可随时终止由本机启动的执行，按原用例重跑未通过项，打包下载完整运行日志与评测报告，并集中维护全局默认基线。

通用偏好保存在 **设置 → Eval** 中，后续新建评估时会自动套用，亦可在每次单次运行中单独覆盖。未经真实验证的模型、执行路径或 Agent 平台会清晰标注为未验证状态，详情请参考 [评估 SDK 应用](/zh/eval/applications)。

## 个人记忆与项目知识

Dashboard 为个人记忆和项目知识提供一站式可视化管理界面，摆脱纯命令行维护的繁琐：

- **个人记忆**：分层展示 Core Profile（核心画像）、协作偏好与经历沉淀。支持直接在线编辑记忆卡片、切换生效范围（全局或特定项目）、主动标记校准或一键遗忘，并直观查看最近 7 天的上下文注入命中率。
- **项目知识**：清晰展示项目模型（架构拓扑、模块依赖与技术事实）和项目策略（架构决策、稳定模式与工程规范）。提供交互式检索测试工具，输入模拟任务即可实时核对命中的知识卡片与 `whyApplied` 触发理由。
- **项目记忆**：在专用标签页中集中管理由 Agent 写入的 Markdown 经验片段，支持全文检索与清理维护。
- **存储与服务配置**：在 **设置** 中自由切换内置文件存储或外部兼容器服务。外部服务支持配置自定义请求端点与鉴权 Token。

## 运行性能观测

进入 **可观测** 模块默认展示 **运行性能** 仪表盘。右上角时间筛选器默认显示 **所有**，并支持最近 1 小时、24 小时、3 天、7 天及自定义时间跨度；运行性能、Change 链路、个人记忆与项目知识联动响应，面板上的汇总指标会随选定区间实时计算。切换至 **所有** 时不再按时间裁剪历史数据，但仍受各视图的最大读取条数上限约束；若触发条数上限会弹出截断提示，不影响底层的物理保留策略。Runtime 健康与 SDK 执行质量始终展示当前实时快照。

在 **可观测 → 运行性能** 下可自由切换全部、Native 或 Classic 视图，全景查看命令调用频次、整体成功率、1 秒内极速响应占比、检查通过率以及耗时 P50/P95 分位数。命令热点榜单支持按调用量或累计耗时升降序排列；结果分布如实反映非零退出码分布，慢执行记录支持一键展开排查明细。Git 命令调用与耗时汇总展示在命令热点下方，各项健康检查单独计费，复用既有检查结果不会被误计为重复执行。

统计样本严格取自当前工作区最近 7 天新采集的本地流水，物理最多保留 10,000 条，前端最多加载最近 5,000 条；触发截断时会有明确标注。命令耗时仅度量执行时间，不包含 CLI 自身启动及模型的推理思考时间，亦不指代 Agent 搞定整项任务的耗时。诸如 Help 查阅、Hook 钩子调用及 Dashboard 本身预览不纳入采样，版本升级前的历史数据不会回溯补录。

**Runtime 健康** 模块实时展示当前 CLI 版本、当前本机环境的常驻处理请求、活动中请求、内存占用及已运行时间。该状态读取为非侵入式轻量查询，不额外拉起后台进程，不占用命令调用配额，亦不会打扰空闲超时机制；若当前无常驻守护进程会如实标注。**SDK 执行质量** 模块读取当前项目至多 50 个 SDK 运行快照，集中分析成功动作、首轮成功率、重试次数、待确认项及待核对动作分布。该快照独立于 Native/Classic 筛选及 7 天窗口；首轮成功率的分母仅统计已终态的动作，不可读数据或物理截断会清晰警示。

## Change 执行链路追踪

时间筛选严格以任务开始执行的时间戳为基准，未记录起始时间的历史快照不参与时间窗筛选。

进入 **可观测 → Change 链路**，支持按 Native、Classic 或具体 Change 筛选任务流。展开链路树即可一览动作、守卫检查、上下文检索、挂起等待与自动重试；点击链路节点即可在右侧展开其起止时间戳、重试轮次、结果摘要及绑定的子任务（窄屏下自动切换为模态弹窗展示）。

甘特时间条在加载时平滑展开，点击节点即时高亮，运行中的执行节点带有呼吸状态动效；后台数据静默刷新时不会重复播放入场动画，在操作系统启用了“减少动态效果”时会自动停用所有动画。看板每 15 秒自动同步一次，刷新时完整保持当前选中的记录与树形折叠状态。观测统计的执行时长会自动合并并行区间并扣除人工等待用时；阶段跨度条完整反映子节点包含调度间隙在内的全生命周期。历史快照保留原汁原味的数据结构与状态，对于缺失打点的历史字段明确标记为未知，绝不凭空臆造模型调用、工具使用、Token 消耗或费用。

执行计时的采样数据按当前工作区物理隔离，滚动保留最近 7 天、至多 10,000 个链路节点；列表视图默认拉取最近 5,000 个节点，单条详情最多展示 2,000 个节点。历史快照按每种工作流各读取至多 50 个 Run，局部数据损坏或截断时会友好提示。链路看板纯属只读观测体系，绝不擅自越权确认决策或代推工作流。

## 产物预览、刷新与平滑更新

产物中心支持高质量全量预览 Markdown、JSON 及各类结构化数据，长篇大作不再受限于字节截断。Native 与 Classic 的文档预览均支持全屏模式及目录导航；再次点击全屏图标或敲击 `Escape` 即可随时退回抽屉视图。所有的日志与评测报告均保留一键下载链接，展示层会自动过滤清洗潜在的不可信 HTML 内容。

数据刷新时完整保留你已选取的条目、表单输入与滚动进度，首次加载展示骨架屏占位，后台静默拉取更新绝不闪烁重置内容。**设置 → 外观** 提供了可视化的主题卡片，支持一键切换浅色或深色主题，并支持平滑缩放字体大小；修改即时生效，且在当前浏览器内跨项目持久保存。官网内置的演示固定锁定为浅色主题。切换主题与多语言时始终保持当前路由导航不变，并严格遵循系统关于减少动态效果的偏好设置。

侧边栏底部清晰呈现当前运行版本与新版更新角标。在执行更新前支持核对影响的项目范围，并在弹窗内实时回显 CLI 及 npm 的输出日志、失败提示与自动重试状态；即使关闭弹窗，后台仍会继续更新，随时可重新点开查看进度。

项目选择器会自动用醒目标记提示物理目录已不存在的“失效项目”。点击 **从索引移除** 仅安全清理 Dashboard 内部的索引记录，绝不会触碰本地物理文件或其他正常项目的配置。
