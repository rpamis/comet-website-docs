Welcome to **Comet** (`@rpamis/comet`) — the CLI tool that chains [OpenSpec](https://github.com/Fission-AI/OpenSpec) and [Superpowers](https://github.com/obra/superpowers) into a single, five-phase automated development workflow. One command takes your idea through proposal, deep design, implementation, verification, and archival — with automatic phase detection so you can always pick up right where you left off.

## Get Started in Three Steps

<Steps>
  <Step title="Install Comet globally">
    Install the Comet CLI from npm so the `comet` command is available everywhere on your machine.

    ```bash
    npm install -g @rpamis/comet
    ```
  </Step>
  <Step title="Run comet init in your project">
    Navigate to your project root and initialise Comet. The interactive wizard lets you pick install scope (project or global), select your preferred language for the skills, and choose your installed AI platforms.

    ```bash
    cd your-project
    comet init
    ```
  </Step>
  <Step title="Invoke /comet in your AI coding tool">
    Open Claude Code, Cursor, Windsurf, or any other [supported platform](/platforms) and type `/comet`. Comet reads the active spec, detects which phase you're in, and continues the workflow automatically.

    ```
    /comet
    ```
  </Step>
</Steps>
