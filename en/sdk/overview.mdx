---
title: 'Comet SDK'
description: 'Integrate recoverable workflows, complete Skill applications, and plugins into your existing Agent platform.'
---

Comet SDK saves execution records, user decisions, and validation evidence for Skill workflows, with APIs for recovery after interruption. Your platform continues to manage model requests, tool calls, Skill loading, and user interaction.

If you want an Agent to create a workflow from a goal, start with [Comet Any](/en/skill-creator/getting-started). Use the SDK described here to define workflows in your own product or integrate a host executor.

## Choose an integration layer

| What you want to implement                                                              | Entry                                     |
| --------------------------------------------------------------------------------------- | ----------------------------------------- |
| Steps, approvals, parallel dependencies, and recovery                                   | Workflow Runtime                          |
| An installable application with a workflow, entry Skill, rules, and pinned dependencies | Workflow Application                      |
| Team work added to Native or Classic                                                    | The existing domain's application factory |
| Memory, knowledge, context, or other capabilities                                       | Plugin SDK                                |

Runtime manages Runs, Actions, and Waits. Application pins actual Skills, modules, artifact contracts, and installation identity on top of Runtime. Plugin SDK manages registration, installation, enabled state, and capability invocation. The host decides when to provide plugin context to the Agent.

## Installation and public entry points

Use Node.js 22.x at version 22.16 or later, or Node.js 24 or later. The SDK uses ESM and includes TypeScript declarations.

```bash
npm install @rpamis/comet@0.5.0
```

| Import path                           | Purpose                                                                                    |
| ------------------------------------- | ------------------------------------------------------------------------------------------ |
| `@rpamis/comet/runtime`               | Workflows, executors, Stores, approvals, and recovery                                      |
| `@rpamis/comet/applications`          | Application loading, Skill adaptation, artifact checks, report templates, and distribution |
| `@rpamis/comet/applications/compiler` | Application assembly from a confirmed plan and isolated artifact validation                |
| `@rpamis/comet/applications/native`   | Native extension factory                                                                   |
| `@rpamis/comet/applications/classic`  | Classic full, hotfix, and tweak composition factory                                        |
| `@rpamis/comet/applications/creator`  | Recoverable authoring workflow and observation APIs                                        |
| `@rpamis/comet/plugins`               | General plugin Runtime, definitions, storage, and type helpers                             |
| `@rpamis/comet/plugins/comet`         | Comet plugin integration with personal memory and project knowledge                        |

Importing the base Runtime does not automatically start an Agent or assemble Native, Classic, personal memory, or project knowledge. Choose entry points according to their responsibilities.
