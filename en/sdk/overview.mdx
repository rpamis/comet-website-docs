---
title: 'Comet SDK'
description: 'Connect resumable workflows, complete Skill applications, and plugins to your Agent platform.'
---

Comet SDK records Skill workflow execution, user decisions, and validation evidence, and provides recovery interfaces after interruptions. Your platform supplies model requests, tools, Skill loading, and user interaction.

To have an Agent create a workflow from your goal, start with [Compose any Skill](/en/skill-creator/getting-started). Use the SDK to define workflows in your product or connect host executors.

## Choose an integration layer

| Your task                                                        | Entry point                           |
| ---------------------------------------------------------------- | ------------------------------------- |
| Define steps, approvals, parallel dependencies, and recovery.    | Workflow Runtime                      |
| Package a workflow, entry Skill, rules, and pinned dependencies. | Workflow Application                  |
| Add team tasks to Native or Classic.                             | The corresponding application factory |
| Provide memory, knowledge, context, or other capabilities.       | Plugin SDK                            |

Runtime manages Runs, Actions, and Waits. Application pins actual Skills, modules, artifact contracts, and installation identity. Plugin SDK manages registration, installation, enabled status, and capability calls; the host decides when to provide plugin context to an Agent.

## What you can build

| Your scenario                                                 | SDK behavior                                                               | Guide                                                                                              |
| ------------------------------------------------------------- | -------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| Call several Skills or tools in order.                        | Record each action and its actual result, following declared transitions.  | [Execute Skills and tools](/en/sdk/executors)                                                      |
| Prepare a draft and sources independently, then combine them. | Make independent actions ready and wait for required results with join.    | [Branches, parallel steps, and joins](/en/sdk/parallel)                                            |
| Reuse a group of checks across workflows.                     | Create a linked child Run and wait for its result.                         | [Child workflows](/en/sdk/subworkflows)                                                            |
| Let a user inspect a draft before publishing.                 | Save a proposal and bind the decision to its current content.              | [User approvals](/en/sdk/approvals)                                                                |
| Wait for a test report or review receipt.                     | Verify evidence ownership and its actual hash before continuing.           | [Evidence waits](/en/sdk/evidence)                                                                 |
| Reject well-formed results that fail business requirements.   | Check output structure, business conditions, and actual files separately.  | [Output validation](/en/sdk/output-validation), [artifact validation](/en/sdk/artifact-validation) |
| Resume yesterday's task after closing the app.                | Persist the Run and resume with its original identity and version.         | [Persistence](/en/sdk/persistence), [unknown results](/en/sdk/recovery)                            |
| Revise a result for at most two rounds.                       | Save business state and select the next declared step.                     | [Business state and loops](/en/sdk/state)                                                          |
| Deliver an installable workflow to your team.                 | Pin the entry, module, and dependencies; preview and confirm installation. | [Applications](/en/sdk/applications), [distribution](/en/sdk/distribution)                         |
| Add team Skills to a development workflow.                    | Extend Native or Classic within their existing acceptance conditions.      | [Workflow composition](/en/sdk/composition)                                                        |
| Add knowledge, memory, or other host capabilities.            | Manage plugin lifecycle and named capability calls.                        | [Plugins](/en/sdk/plugins)                                                                         |

Start with [your first workflow](/en/sdk/quickstart), then replace local handlers with calls to your existing Agent. Package an Application when you need platform installation and complete Skill dependencies. Basic Runtime is sufficient for trying scheduling behavior.

## Installation and public entry points

Use Node.js 22.x starting at 22.16, or Node.js 24 and later. The SDK uses ESM and includes TypeScript declarations.

```bash
npm install @rpamis/comet@0.5.0
```

| Import path                           | Purpose                                                                  |
| ------------------------------------- | ------------------------------------------------------------------------ |
| `@rpamis/comet/runtime`               | Workflow, executors, Store, approvals, and recovery.                     |
| `@rpamis/comet/applications`          | Loading, Skill adaptation, artifact checks, report sample, and delivery. |
| `@rpamis/comet/applications/compiler` | Assemble confirmed plans and validate isolated artifacts.                |
| `@rpamis/comet/applications/native`   | Native extension factory.                                                |
| `@rpamis/comet/applications/classic`  | Classic full, hotfix, and tweak composition factories.                   |
| `@rpamis/comet/applications/creator`  | Resumable creation flow and observation interfaces.                      |
| `@rpamis/comet/plugins`               | Generic plugin Runtime, definitions, stores, and type helpers.           |
| `@rpamis/comet/plugins/comet`         | Comet integration with personal memory and project knowledge.            |

Importing basic Runtime does not start an Agent or assemble Native, Classic, personal memory, or project knowledge. Choose entry points for the responsibilities you need.
