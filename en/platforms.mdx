Comet installs Skills, rules, and necessary hooks directly into each AI coding platform's designated directory. When you run `comet init`, Comet writes the skill files and automation scripts into the correct subdirectory so your platform can discover them automatically. No manual file copying or path configuration is required. As of 0.4.0-beta.1, Comet supports **31** AI coding platforms.

## Capability summary

### Rule formats

Comet supports three rule formats:

| Format | Platforms |
| --- | --- |
| `md` | Most platforms with rules |
| `mdc` | Cursor only (Cursor MDC frontmatter) |
| `copilot` | GitHub Copilot only |

### Hook formats

The 9 platforms that support hooks use 7 hook formats:

| Hook format | Output file | Platforms |
| --- | --- | --- |
| `claude-code` | `settings.local.json` | Claude Code, Codex, Amazon Q |
| `qwen` | `settings.json` | Qwen Code |
| `qoder` | `settings.json` | Qoder |
| `gemini` | `settings.json` | Gemini CLI |
| `windsurf` | `hooks.json` | Windsurf |
| `copilot` | `hooks/<id>.json` | GitHub Copilot |
| `kiro` | `hooks/<id>.kiro.hook` | Kiro |

### OpenCode-derived platforms

OpenCode, ZCode, and MimoCode all build on the OpenCode runtime and support OpenCode-style slash commands and mirrored OpenSpec output:

| Platform | Mirroring behavior |
| --- | --- |
| OpenCode | Native support |
| ZCode | Migrates `.opencode/{skills,commands}` and mirrors to `.zcode/` |
| MimoCode | Mirrors OpenSpec output to `.mimocode/` |

## Special install paths

The following platforms use a different directory for global installs:

| Platform | Project dir | Global dir |
| --- | --- | --- |
| OpenCode | `.opencode` | `~/.config/opencode` |
| MimoCode | `.mimocode` | `~/.config/mimocode` |
| Antigravity | `.agents` | `~/.gemini/antigravity` |
| Pi | `.pi` | `~/.pi/agent` |

For all other platforms, the global install uses the same directory name under your home directory (e.g. `~/.claude/` for Claude Code). Junie, CodeBuddy Code, CoStrict, Crush, Factory Droid, iFlow, Bob Shell, and ForgeCode do not support global installs.

<Tip>
  `comet init` automatically detects platform config directories already present in your project and pre-selects them. Use `--yes` to skip the prompt and install to all detected platforms.
</Tip>

## Project vs global scope

| Scope | Best for | Behavior |
| --- | --- | --- |
| project | Team repos, shared conventions, committed config | Writes config into the current project for collaboration |
| global | Personal defaults, shared across projects | Writes config into your home directory |

## OpenClaw, Hermes, and other generic platforms

Some AI coding platforms use a generic `skills` CLI registry rather than a platform-specific directory convention. For these platforms — including OpenClaw and Hermes — install the Comet skill bundle directly via:

```bash
npx skills add rpamis/comet
```

This fetches the Comet skill package from the generic skills registry and installs it into the platform's expected location. It does not conflict with `comet init` for other platforms — each targets a different directory.

## Platform auto-detection

`comet init` automatically detects which AI coding platforms are already installed in your project by checking for their configuration directories (e.g. if `.claude/` exists, Claude Code is detected and pre-selected). To skip the interactive prompt entirely and install to all auto-detected platforms, use the `--yes` flag:

```bash
comet init --yes --scope project
```

If no platforms are detected, `--yes` selects all platforms.

## After installation

Once `comet init` completes, each platform's skills directory will contain the Comet, OpenSpec, and Superpowers skills plus the Comet scripts:

```
.claude/skills/           ← example: Claude Code
├── comet/
│   ├── SKILL.md          ← /comet main entry
│   └── scripts/
│       ├── comet-guard.mjs
│       ├── comet-env.mjs
│       ├── comet-handoff.mjs
│       ├── comet-archive.mjs
│       ├── comet-yaml-validate.mjs
│       └── comet-state.mjs
├── comet-open/SKILL.md
├── comet-design/SKILL.md
├── comet-build/SKILL.md
├── comet-verify/SKILL.md
├── comet-archive/SKILL.md
├── comet-hotfix/SKILL.md
├── comet-tweak/SKILL.md
├── openspec-*/SKILL.md   ← OpenSpec skills
└── brainstorming/SKILL.md ← Superpowers skills
```

<Note>
  0.4.0-beta.1 ships `.mjs` Node entrypoints instead of the old `.sh` shell scripts. No Bash, Git Bash, or WSL is required on any platform.
</Note>

Run `comet doctor` at any time to verify that skill files, scripts, and working directories are all present and healthy:

```bash
comet doctor
```
