## Prerequisites

You need:

- Node.js 20 or newer.
- npm.
- A supported AI coding tool, such as Claude Code, Codex, Cursor, Windsurf, GitHub Copilot, Gemini CLI, or another [supported platform](/en/platforms).

## 1. Install the CLI

```bash
npm install -g @rpamis/comet
```

Check that the command is available:

```bash
comet --version
```

## 2. Initialize your project

Run `comet init` from the project root.

```bash
cd your-project
comet init
```

The wizard asks for:

- install scope: project or global;
- preferred Skill language. Project-level installs write the matching artifact language to `.comet/config.yaml`: `English` maps to `en`, and `中文` maps to `zh-CN`;
- target AI coding platforms;
- copy or symlink install mode when supported.

Comet detects existing platform folders and avoids overwriting user-owned files without confirmation.

## 3. Call `/comet`

Open your AI coding tool in the same project and type:

```text
/comet add the feature you want
```

Comet reads the repository state, creates or resumes the active change, and routes the request to the right phase. A new change snapshots `language` from `.comet/config.yaml`, so proposal, design, tasks, verification reports, and archive notes keep the same primary language.

## 4. Check state

Use `comet status` when you want a compact local view.

```bash
comet status
```

Use the dashboard when you want a read-only browser view.

```bash
comet dashboard .
```

## 5. Resume interrupted work

If the session is interrupted, open the project again and call `/comet`. Comet reads `.comet.yaml`, `.comet/run-state.json`, OpenSpec artifacts, and Superpowers artifacts to continue from the current phase.
