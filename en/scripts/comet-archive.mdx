`comet-archive.mjs` is the final workflow step. It runs after verification passes and the branch or worktree status is handled.

## What archive does

- Confirms the workflow is in archive-ready state.
- Syncs accepted delta specs into long-term spec history.
- Preserves proposal, tasks, verification, and handoff evidence.
- Marks the change archived.
- Resets active workflow state so the next `/comet` can start cleanly.

## Dry-run mindset

Archive should be predictable. If required evidence is missing, it should report the blocker instead of producing a partial archive.

## After archive

The active change is closed. Historical files remain available for future recovery, audit, and documentation.
