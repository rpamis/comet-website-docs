`comet dashboard` starts a **local read-only** browser dashboard. From one entry point, you can switch between Classic and Native and inspect active and archived Changes, task progress, acceptance results, risks, artifacts, and Git summaries.

The demo below is fully interactive. It does not read or modify your project.

## Start

Run this command from the project root:

```bash
comet dashboard
```

Dashboard opens at `http://localhost:4321` by default. Use `--port <port>` to select another port or `--no-open` to start the service without opening a browser.

<Info>
  The service binds only to <code>127.0.0.1</code>. It is not exposed externally and does not modify project files.
</Info>

## Classic and Native

The **Classic / Native** switch in the upper-left corner selects the current workspace. Both views share the Change Explorer, detail area, status sidebar, and artifact preview, but they are never mixed together.

|                    | Classic                                      | Native                                              |
| ------------------ | -------------------------------------------- | --------------------------------------------------- |
| Lifecycle          | open → design → build → verify → archive     | Shape → Build → Verify → Archive                    |
| Primary information | Tasks, artifacts, Verify, risks, and Git    | Loop, acceptance, checks, blockers, recovery, and user artifacts |
| Active and archived | Supported                                    | Supported                                           |
| Modify or advance Changes | Not supported                             | Not supported                                       |

After selecting a Change, you can inspect its current phase, task or acceptance progress, next action, risks, and artifacts. Use `comet status` or `comet native status --details` for complete diagnostics.

## Supervisor Change and Git worktrees

Dashboard scans the worktrees registered for the current Git repository and preserves the branch or directory label for each workspace.

A Native Supervisor Change shows child completion progress. Expand the parent to select a child and inspect its phase, workspace, dependencies, and acceptance status. Dashboard discovers and displays this state; it does not create worktrees, advance tasks, or run verification.

## Artifact previews

Select a generated artifact to open the Markdown preview drawer. It supports:

- headings, lists, tables, task lists, and syntax highlighting;
- Mermaid diagrams;
- structured tables for `.comet.yaml`, handoff, and checkpoint files;
- user-readable Classic and Native artifacts.

Content larger than 256 KiB is truncated and marked. Artifact content is sanitized before rendering, so HTML or Mermaid cannot execute scripts.

## Theme, refresh, and demo data

- Use the top toolbar to switch between light and dark themes. The selection is stored in the current browser.
- Dashboard refreshes automatically every 30 seconds, or you can refresh immediately from the toolbar.
- Add `?demo` to load demo data without reading real Changes:

```text
http://localhost:4321/?demo
```

## Boundaries

Dashboard does not advance, repair, verify, or archive Changes. It does not expose absolute paths, raw logs, or local Runtime files. All state changes still go through `/comet`, `/comet-native`, and the corresponding CLI commands.

If collection fails for one workflow, Dashboard shows the error instead of presenting an empty workspace. The other workflow can continue displaying normally.
