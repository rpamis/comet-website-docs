---
title: "comet eval"
description: "Evaluate a local Skill or comet/eval.yaml with the shared eval harness and generate reports."
---

## Command forms

```bash
comet eval --manifest comet/eval.yaml
comet eval --skill-path ./skills/my-skill
```

## Before running

Prepare a `comet/eval.yaml` manifest, a local Skill path with eval metadata, or a package generated by Skill Creator.

## Recommended path

Start with collect-only mode when you are validating discovery.

```bash
comet eval --manifest comet/eval.yaml --collect-only
```

Then run the full evaluation.

```bash
comet eval --manifest comet/eval.yaml
```

## Options

| Option | Purpose |
| --- | --- |
| `--manifest` | Use an explicit eval manifest. |
| `--skill-path` | Evaluate a local Skill package. |
| `--profile` | Select an execution profile. |
| `--task` | Run a subset of tasks. |
| `--collect-only` | Validate discovery without full execution. |
| `--json` | Print machine-readable output. |

## Difference from `comet skill check`

`comet skill check` validates targeted package behavior. `comet eval` runs a scoring harness with tasks, metrics, and reports.
