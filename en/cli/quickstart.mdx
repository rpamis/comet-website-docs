## Prerequisites

Install Node.js 20 or newer and npm.

## Step 1: install Comet

```bash
npm install -g @rpamis/comet
```

## Step 2: initialize a project

```bash
cd your-project
comet init
```

The wizard detects supported AI coding platforms and installs the selected Comet Skills, rules, and hooks.

## Step 3: daily commands

### Resume the workflow: `comet status`

```bash
comet status
```

Use this before or after `/comet` when you want to know the active phase, change id, mode, and recovery hints.

### Troubleshoot: `comet doctor`

```bash
comet doctor
```

Use this when platform files, installed assets, or runtime entrypoints look wrong.

## Upgrade and uninstall

```bash
npm install -g @rpamis/comet@latest
comet update
comet uninstall
```
