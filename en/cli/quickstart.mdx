This page is the shortest onboarding path for the Comet CLI. Just three commands cover installation, checking, and recovery. For the full options of each command, see the [advanced topics](#advanced-topics).

## Prerequisites

- Node.js 20+
- npm/npx
- Git

<Info>
  Since 0.4.0-beta.1, Comet is a pure Node runtime and no longer requires Bash, Git Bash, or WSL.
  macOS, Linux, and Windows use the same set of commands.
</Info>

## Step 1: Install Comet

Install the CLI globally:

```bash
npm install -g @rpamis/comet
```

## Step 2: Initialize the project

Run it in the project root:

```bash
comet init
```

It detects your AI coding platform. A new project-scope initialization installs self-contained Native by default and writes `comet.config.yaml` plus `comet/`; projects with clear existing Classic state keep their current workflow.

Choose explicitly when needed:

```bash
comet init --workflow native --root docs
comet init --workflow classic
```

Only the Classic path installs OpenSpec, Superpowers, and the corresponding rules and hooks. A global initialization installs global capabilities only; it does not select a default workflow for a project.

### Troubleshooting: comet doctor

If `comet status` shows something abnormal, or the installation looks off:

```bash
comet doctor
```

It checks both project-level and global installations, platform directories, Skills, scripts, and active change status, and provides recovery hints.

## Upgrade and uninstall

Upgrade to the latest version from your project directory:

```bash
comet update
```

It automatically updates the npm package and refreshes Comet Skill dependencies.

Uninstall Comet-managed Skills, hooks, and rules while preserving your OpenSpec changes, design documents, and code:

```bash
comet uninstall
```

## FAQ

<Accordion title="Where does comet init install to?">
  By default it detects the AI coding platform directories in the current project. Use `--scope
  project` for project-level only, or `--scope global` for a global install.
</Accordion>

<Accordion title="Do scripts run on Windows?">
  Since 0.4.0-beta.1, all scripts run through Node.js, so Windows no longer requires Git Bash or
  WSL.
</Accordion>
