---
title: "comet dashboard"
description: "Start a local read-only browser dashboard for active and archived changes, phase progress, artifacts, tasks, and risks."
---

## Quick start

```bash
comet dashboard .
```

The command starts a local server and opens a browser view for the current repository.

## Options

| Option | Purpose |
| --- | --- |
| `--host` | Bind to a specific host. |
| `--port` | Choose a port. |
| `--no-open` | Start the server without opening a browser. |
| `--json` | Print machine-readable startup information. |

### Script and CI usage

Use `--json` and `--no-open` when automation needs the URL without launching a browser.

```bash
comet dashboard . --no-open --json
```

## What the dashboard shows

- active change;
- current phase and mode;
- workflow files;
- project configuration;
- proposal, spec, design, implementation, verification, and archive links;
- risk codes for missing artifacts or ambiguous state.

## Safety

The dashboard is read-only. Use the CLI or `/comet` for state-changing actions.
