---
title: "comet skill"
description: "Manage local Comet Skill packages and debug advanced deterministic Engine runs."
---

## Subcommands

| Command | Purpose |
| --- | --- |
| `comet skill add` | Add or install a local Skill package. |
| `comet skill show` | Inspect Skill package metadata. |
| `comet skill run` | Start an advanced deterministic Engine run. |
| `comet skill continue` | Continue or submit results to a run. |
| `comet skill check` | Run targeted checks for a Skill. |

## Common options

| Option | Purpose |
| --- | --- |
| `--cwd` | Choose the working directory. |
| `--json` | Emit machine-readable output. |
| `--verbose` | Include additional diagnostics. |

## Run lifecycle

`run` creates a run record, validates inputs, and prepares deterministic execution state.

`continue` resumes a run or records a result after an external agent step.

`check` runs targeted validation without going through a full eval harness.

## Run state storage

Run state belongs under `.comet/` and is machine-managed. Do not hand-edit it unless you are debugging with a clear rollback path.
