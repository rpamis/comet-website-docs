## Main files

| File | Purpose |
| --- | --- |
| `summary.html` | Human-readable report. |
| `report.json` | Machine-readable metrics and run details. |
| Run logs | Per-attempt trace and artifacts. |

## What to read first

1. Overall pass rates.
2. `pass@k` vs `pass^k` gap.
3. Rubric dimension scores.
4. Failure attribution.
5. Per-run traces for representative failures.

## How to act on failures

| Attribution | First action |
| --- | --- |
| `harness` | Fix eval setup or environment. |
| `task` | Clarify task or validation. |
| `workflow` | Fix Skill instructions or runtime contract. |
| `model` | Re-run, tune prompt, or change model if justified. |
