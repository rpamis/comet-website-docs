The eval harness isolates task execution, records agent behavior, runs validation, and scores outcomes.

  <img src="/assets/eval-harness-illustrations/01-docker-agent-rubric-scene.png" alt="Xiaoyu observes the subject agent, user simulator, Docker box, and rubric judge in an eval harness" width="800" />
</p>

## Main pieces

| Piece | Role |
| --- | --- |
| Subject agent | Runs the task with the selected treatment. |
| Simulator agent | Responds at decision points in `auto_user` mode. |
| Docker environment | Runs validation in isolation. |
| Validation script | Produces pass/fail facts. |
| Rubric judge | Scores qualitative dimensions. |

## Collect mode

`--collect` discovers tasks and validates configuration without running model attempts.
