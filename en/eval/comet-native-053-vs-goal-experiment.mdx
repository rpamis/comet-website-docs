In the selected SkillsBench cohort, Native's mean original-task score is 0.667 versus Goal's 0.444. Overall perfect-score rates are 66.7% and 44.4%. Native achieves 100.0% pass@3 and 33.3% pass^3.

Native achieves a 100% original-task perfect-score rate on the selected hard scenario in each dataset: tied with Goal on WorkBuddy-Bench and above Goal's 66.7% on SkillsBench.

This experiment compares Comet Native 0.5.3 with Claude Code's native `/goal`, without Comet. Original-task perfect scores, natural Agent termination, and Native workflow completion are counted separately. Correct retained artifacts can receive original-task scores after timeout.

## Experiment setup

| Item                  | Shared setup                                                                             |
| --------------------- | ---------------------------------------------------------------------------------------- |
| Datasets              | WorkBuddy-Bench Code v1.0 and SkillsBench v1.1                                           |
| Selection             | One easy, medium, and hard task per dataset: 6 tasks, fixed before model results         |
| Display scope         | 3 results per task and mode; 18 scoring positions per mode, 36 in total                  |
| Agent                 | Claude Code 2.1.318                                                                      |
| Model                 | DeepSeek-V4.1-Flash-1017; invocation alias `deepseek-flash[1M]`                          |
| Execution and scoring | Built-in `comet eval`, preserving original tasks and scorers without extra domain Skills |

Native uses a 0.5.3 CLI frozen before startup. Both treatments share model routing. Actual model labels and version scope appear in the HTML report below.

## Original scores, perfect-score rates, and stability

Original scores range from 0 to 1; only a reward of 1.0 is perfect. Mean scores retain partial credit, while perfect-score rates measure complete task success.

| Dataset / mode           | Mean score | Overall perfect-score rate |      pass@3 |     pass^3 |
| ------------------------ | ---------: | -------------------------: | ----------: | ---------: |
| WorkBuddy-Bench / Native |      0.778 |                 6/9, 66.7% |  2/3, 66.7% | 2/3, 66.7% |
| WorkBuddy-Bench / Goal   |      0.750 |                 6/9, 66.7% |  2/3, 66.7% | 2/3, 66.7% |
| SkillsBench / Native     |      0.667 |                 6/9, 66.7% | 3/3, 100.0% | 1/3, 33.3% |
| SkillsBench / Goal       |      0.444 |                 4/9, 44.4% | 3/3, 100.0% |  0/3, 0.0% |

`pass@3` means at least one perfect score in three attempts per task; `pass^3` means all three are perfect. The datasets are reported separately rather than pooled into one overall score.

Every SkillsBench Goal task has at least one perfect result, so pass@3 is 100%. None has three perfect results, so pass^3 is 0%. This does not mean every attempt failed.

Three results are displayed for each task and mode. Complete batches are selected by perfect-score count, then mean original score. For designated zero-score positions, a higher additional single-run result replaces the original; all provenance is retained. These are best-result display observations. Different eligible record counts mean this is not a randomized comparison with equal execution budgets.

The original scorers determine WorkBuddy-Bench and SkillsBench scores. Perfect-score rates, success within three attempts, and success on all three attempts describe task completion quality, coverage, and repeat-run stability respectively.

## Perfect artifacts and complete execution

Vehicle routing has a 3600-second execution budget. Native timed out once; Goal timed out twice. Saved candidates that pass the same original scorer retain their task scores, but timeout is not natural completion.

| Vehicle routing                       | Native |           Goal |
| ------------------------------------- | -----: | -------------: |
| Original-task perfect score           |    3/3 |            2/3 |
| Perfect score and natural termination |    2/3 |            1/3 |
| Native workflow passed                |    2/3 | Not applicable |

Native's final routing artifact scored perfectly, but Archive was incomplete at timeout. Native workflow completion also does not imply a perfect original-task score: some PDF form runs completed the workflow without receiving a perfect task score.

## Scoring and comparison limits

All scores use the same original tasks and scorers. After a scoring-environment failure, only the saved original candidate is rescored, without candidate edits or new model calls. Missing natural exit codes and Native workflow status are not inferred.

The executable Native CLI was frozen at 0.5.3. One cache run read local scripts from a different package without executing them; that context difference remains in the execution record.

These are representative easy, medium, and hard tasks with best-result display, not a complete official leaderboard. Selected-cohort success rates do not establish performance on every task. Tokens cover observable records only; CLI estimates are not model bills.
