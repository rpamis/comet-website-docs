Comet separates capability from reliability.

<p align="center">
  <img src="/assets/eval-scoring-illustrations/01-pass-k-reliability.png" alt="Xiaoyu compares pass@k as at least one success with pass^k as every run succeeding reliably" width="800" />
</p>

| Metric | Meaning |
| --- | --- |
| `pass@k` | At least one of k attempts passed. Shows upper-bound capability. |
| `pass^k` | All k attempts passed. Shows reliability. |

For workflow Skills, reliability matters more than occasional success.

## Profiles

| Profile | Dimensions | Interaction |
| --- | --- | --- |
| `generic` | Generic task completion, artifacts, instruction following, Skill use. | Single turn. |
| `comet-workflow` | Phase discipline, artifacts, decisions, recovery, verification. | `auto_user`. |
| `authoring-skill` | Workflow protocol, generated package quality, evidence, review readiness. | `auto_user`. |

## Dual-agent evaluation

`auto_user` runs a subject agent and a simulator agent. The simulator replies at decision points so the workflow can progress without a human sitting in the loop.

## Failure attribution

Failures are attributed to harness, workflow, task, or model. Use attribution before changing the Skill; not every failure is a Skill bug.
