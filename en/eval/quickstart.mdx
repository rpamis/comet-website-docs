title: "Eval quickstart"
description: "Run comet eval with collect mode first, then generate an HTML report for Skill quality evidence."
---

Use `comet eval` when you need evidence that a Skill works, not just a manual impression.

## 1. Start with collect mode

```bash
comet eval ./generated-skill/comet/eval.yaml --collect
```

Collect mode checks discovery and configuration without spending model tokens.

  <img src="/assets/eval-quickstart-illustrations/01-collect-run.png" alt="Xiaoyu moves a Skill card from low-cost collect precheck to the real HTML eval report tray" width="800" />

## 2. Run the real eval

```bash
comet eval ./generated-skill/comet/eval.yaml --html
```

The report includes summary metrics, per-run traces, rubric scores, token/cost attribution, and failure attribution.

## 3. Read the result

Focus on:

| Signal | Meaning |
| --- | --- |
| `pass@k` | At least one run succeeded. Capability ceiling. |
| `pass^k` | Every run succeeded. Reliability floor. |
| Dimension scores | Which behavior is weak. |
| Attribution | Whether failure came from harness, workflow, task, or model. |
