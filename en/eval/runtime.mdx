description: "Understand the difference between comet eval quality evidence and comet skill check runtime-completeness checks."
---

`comet eval` and `comet skill check` are related but not interchangeable.

<p align="center">
  <img src="/assets/eval-runtime-illustrations/01-comet-eval-skill-eval-boundary.png" alt="Xiaoyu separates comet eval publish evidence from comet skill check run-completeness inspection" width="800" />
</p>

| Command | Checks | Use for |
| --- | --- | --- |
| `comet eval` | Task success, rubric quality, reliability, attribution. | Release evidence. |
| `comet skill check` | Whether a specific Engine Run satisfies runtime checks. | Run health and debugging. |

Use eval before publishing. Use skill check while debugging or resuming an Engine Run.
