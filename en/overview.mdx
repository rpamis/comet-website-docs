Welcome to **Comet** (`@rpamis/comet`). Comet provides two independent, recoverable requirements workflows:

- Native serves **strong coding models** with detailed requirements, complete target Specs, state checks, and verification evidence. It does not prescribe a fixed plan, TDD method, or review method.
- Classic connects [OpenSpec](https://github.com/Fission-AI/OpenSpec) and [Superpowers](https://github.com/obra/superpowers), preserving full five-phase governance.

Project-root configuration determines which permanent entry point `/comet` invokes.

## Get started in three steps

<Steps>
  <Step title="Install the Comet CLI globally">
    Install from npm so the `comet` command is available on your machine.

    ```bash
    npm install -g @rpamis/comet
    ```
  </Step>
  <Step title="Run comet init in your project">
    Go to the project root and initialize Comet. The wizard lets you choose project or global install scope, preferred Skill language, and target AI platforms.

    ```bash
    cd your-project
    comet init
    ```
  </Step>
  <Step title="Call /comet from your AI coding tool">
    Open Claude Code, Codex, Cursor, or another [supported platform](/en/platforms), then type `/comet`. A new project-level initialization defaults to Native; an existing Classic project remains Classic. `/comet` reads project configuration and enters the corresponding permanent entry point instead of guessing from task size.

    ```bash
    /comet what you want to build
    ```
  </Step>
</Steps>

## AI-native docs

You can connect the Comet docs site to your agent through MCP, so your assistant can retrieve up-to-date docs during conversations.

### Use with Claude Code

```bash
claude mcp add --transport http docs-comet --scope user https://docs.comet.rpamis.com/mcp
```

### Use with Codex CLI

```bash
codex mcp add docs-comet --url https://docs.comet.rpamis.com/mcp
```

### Use with Cursor/Antigravity

```json
{
  "mcpServers": {
    "docs-comet": {
      "url": "https://docs.comet.rpamis.com/mcp"
    }
  }
}
```

### Use with VS Code
```json
{
  "servers": {
    "docs-comet": {
          "url": "https://docs.comet.rpamis.com/mcp"
    }
  }
}
```
