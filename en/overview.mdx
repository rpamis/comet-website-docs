Welcome to Comet (`@rpamis/comet`). Comet offers two sets of independent recoverable requirement workflows:

- Native provides a strong coding model with detailed requirements, complete target specifications, status checks, and verification evidence services, but does not specify fixed plans, TDD, or review methods.

- The Classic connection [OpenSpec](https://github.com/Fission-AI/OpenSpec)] and [Superpowers](https://github.com/obra/superpowers)] retains the complete five-stage governance.

The project root configuration determines which entry `/comet` is forwarded to.

## Three easy steps to get started

<Steps>
  <Step title="Install Comet CLI on the global Npm">
Install Comet CLI from npm to make the `comet` command available anywhere on your machine

    ```bash
    npm install -g @rpamis/comet
    ```

  </Step>
  <Step title="Run comet init in your project">
Navigate to the project root directory and initialize Comet. The interactive wizard enables you to select the installation scope (project or global), choose the preferred language of the Skill, and select the AI platform to install

    ```bash
    cd your-project
    comet init
    ```

  </Step>
  <Step title="Call /comet in your AI coding tool">
Open Claude Code, Codex, Cursor or any other supported platform ](/en/platforms), and then enter `/comet`. New project-level initialization default configuration Native; existing Classic projects keep Classic. `/comet` only reads the project configuration and enters the corresponding fixed entry, without guessing the mode based on the task size.

    ```bash
/comet What You want to do
    ```

  </Step>
</Steps>

## Ai-native documentation

You can directly connect the Comet document station to your Agent through MCP, and search for the latest document content as needed during conversations.

### Used in Claude Code

```bash
claude mcp add --transport http docs-comet --scope user https://docs.comet.rpamis.com/mcp
```

### Used in Codex CLI

```bash
codex mcp add docs-comet --url https://docs.comet.rpamis.com/mcp
```

### Used in Cursor/Antigravity

```json
{
  "mcpServers": {
    "docs-comet": {
      "url": "https://docs.comet.rpamis.com/mcp"
    }
  }
}
```

### Used in VS Code

```json
{
  "servers": {
    "docs-comet": {
      "url": "https://docs.comet.rpamis.com/mcp"
    }
  }
}
```
