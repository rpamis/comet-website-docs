---
title: "Skill Creator FAQ"
description: "Common questions about /comet-any, generated Skill packages, eval evidence, review, publishing, and distribution."
---

<AccordionGroup>
  <Accordion title="Is /comet-any only generating SKILL.md?">
    No. It generates a stable Skill package with workflow protocol, references, source evidence, eval manifest, and optional scripts/rules/hooks.
  </Accordion>
  <Accordion title="Can I publish without eval evidence?">
    No. Publishing readiness requires evidence tied to the current draft hash.
  </Accordion>
  <Accordion title="Why does Skill Creator ask for confirmation before writing state?">
    The confirmation page is the user gate that prevents hidden composition choices.
  </Accordion>
  <Accordion title="Do I need to understand Bundle and Factory?">
    Usually no. Those terms are implementation details. Use the `/comet-any`, `comet creator`, and `comet publish` surfaces.
  </Accordion>
</AccordionGroup>
