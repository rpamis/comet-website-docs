Use `/comet-any` when you want to create, customize, or upgrade a reusable Skill. It turns your goal into a stable Skill package with source evidence, evaluation hooks, review gates, and distribution output.

## Main path

```text
/comet-any -> confirm plan -> generate draft -> comet eval -> creator status/next -> publish review -> approve -> distribute preview -> distribute
```

## Start

Describe the Skill you want:

```text
/comet-any Create a code review helper for our TypeScript service
```

Skill Creator resolves real local Skills, presents a confirmation page, then creates a draft package.

## Evaluate

```bash
comet eval ./generated-skill/comet/eval.yaml --collect
comet eval ./generated-skill/comet/eval.yaml --html
```

## Check readiness

```bash
comet creator status <name> --project . --json
comet creator next <name> --project . --json
```

## Publish and distribute

```bash
comet publish review <name> --project .
comet publish approve <name> --project .
comet publish run <name> --project .
comet publish distribute <name> --preview --project .
comet publish distribute <name> --project .
```
