Engine is the deterministic runtime used by generated and project Skills. Classic `/comet` users do not need it for normal five-phase work, but Skill authors need to understand its boundaries.

## Core ideas

| Concept | Meaning |
| --- | --- |
| Skill snapshot | Immutable copy of the Skill package used for a run. |
| Run state | Deterministic record of current step, pending action, artifacts, and outcome. |
| Pending action | A required external operation that must be completed before resume. |
| Guardrails | Rules that constrain execution. |
| Runtime checks | Deterministic checks for run completion and evidence. |

## Pending action loop

1. Engine proposes a pending action.
2. External executor performs it.
3. The outcome is submitted through `comet skill continue`.
4. Engine advances or reports the next pending action.
