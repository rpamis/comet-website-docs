In the stratified sample cohort from SkillsBench, Comet Native achieved a mean task score of 0.667 (vs. 0.444 for Goal), with an overall perfect-score rate of 66.7% (vs. 44.4% for Goal). Native achieved a pass@3 of 100.0% and a pass^3 of 33.3%.

Across the hardest scenarios selected from both benchmarks, Native reached a 100% perfect-score rate: tying Goal on WorkBuddy-Bench and outperforming Goal (66.7%) on SkillsBench.

This benchmark compares Comet Native 0.5.3 with unassisted Claude Code native `/goal`. Original-task perfect scores, normal Agent completion, and Native workflow compliance are tallied independently; code artifacts retained after a timeout still receive their original-task score if they pass the assertions.

<h2 id="experiment-setup">Experiment setup</h2>

| Item                  | Shared setup                                                                             |
| --------------------- | ---------------------------------------------------------------------------------------- |
| Datasets              | WorkBuddy-Bench Code v1.0 and SkillsBench v1.1                                           |
| Selection             | One easy, medium, and hard task per dataset: 6 tasks fixed prior to model execution       |
| Sample size           | 3 runs per task and mode; 18 scored runs per mode (36 runs total)                        |
| Agent                 | Claude Code 2.1.318                                                                      |
| Model                 | DeepSeek-V4.1-Flash-1017; invocation alias `deepseek-flash[1M]`                          |
| Execution and scoring | Built-in `comet eval`, preserving original tasks and scorers without extra domain Skills |

Native execution ran on a fixed 0.5.3 CLI release. Both benchmark arms maintained identical model routing; specific model tags and version scopes are detailed in the HTML report below.

<h2 id="original-scores,-perfect-score-rates,-and-stability">
  Original scores, perfect-score rates, and stability
</h2>

Task scores range from 0 to 1; a reward of 1.0 represents a full score. Mean scores reflect partial credit, while perfect-score rates measure complete success.

| Dataset / mode           | Mean score | Overall perfect-score rate |      pass@3 |     pass^3 |
| ------------------------ | ---------: | -------------------------: | ----------: | ---------: |
| WorkBuddy-Bench / Native |      0.778 |                 6/9, 66.7% |  2/3, 66.7% | 2/3, 66.7% |
| WorkBuddy-Bench / Goal   |      0.750 |                 6/9, 66.7% |  2/3, 66.7% | 2/3, 66.7% |
| SkillsBench / Native     |      0.667 |                 6/9, 66.7% | 3/3, 100.0% | 1/3, 33.3% |
| SkillsBench / Goal       |      0.444 |                 4/9, 44.4% | 3/3, 100.0% |  0/3, 0.0% |

`pass@3` indicates at least one perfect score across 3 attempts per task; `pass^3` indicates all 3 attempts achieved a full score. Because the task distributions differ, metrics for both datasets are presented independently rather than pooled into a single score.

Taking Goal's performance on SkillsBench as an example: while every task achieved a perfect score at least once (100% pass@3), no task achieved full marks across all 3 runs (0% pass^3). This shows the model possesses the capability to solve the tasks, but lacks consistency across repeated runs.

Three run records are displayed for each task and mode. Overall comparison prioritizes perfect-score frequency, followed by average task score. For individual slots that scored zero due to transient environmental issues, higher-scoring supplemental runs are displayed while retaining full provenance. Note that displayed metrics reflect observed best-run values; differing candidate pool sizes mean this is not an equal-budget randomized controlled trial.

WorkBuddy-Bench and SkillsBench were scored strictly according to original benchmark criteria. The perfect-score rate reflects delivery quality, succeeding within 3 attempts (pass@3) indicates capability coverage, and succeeding across all 3 attempts (pass^3) measures repeat-run stability.

<h2 id="perfect-artifacts-and-complete-execution">Perfect artifacts and complete execution</h2>

The single-run timeout budget for vehicle routing was 3600 seconds. Native encountered 1 timeout, while Goal encountered 2 timeouts. Retained code artifacts passed original scorer assertions upon timeout, so their task scores are included in the table above, though they are not marked as natural completions.

| Vehicle routing                       | Native |           Goal |
| ------------------------------------- | -----: | -------------: |
| Original-task perfect score           |    3/3 |            2/3 |
| Perfect score and natural termination |    2/3 |            1/3 |
| Native workflow passed                |    2/3 | Not applicable |

In Native's third vehicle routing attempt, the resulting code achieved a perfect score, but execution timed out before completing the Archive phase. Furthermore, Native workflow compliance and original task scores are evaluated independently: in the PDF form task, for example, certain runs achieved workflow compliance without reaching a perfect task score.

<h2 id="scoring-and-comparison-limits">Scoring and comparison limits</h2>

All scores derive from original task definitions and official benchmark scorers. When test environment anomalies occurred, evaluation was performed directly on the saved code candidates without editing code, re-invoking models, or inferring missing exit codes and workflow states.

Native runs used a locked 0.5.3 CLI version. In one cache run, the Agent inspected a local directory containing external scripts but did not execute them; this context artifact remains documented in the execution logs.

This evaluation represents stratified sampling across easy, medium, and hard difficulty tiers with best-run presentation, rather than a full official leaderboard sweep. Cohort pass rates should not be extrapolated directly to all possible tasks. Token totals cover observable primary-session activity only; CLI cost estimates do not represent actual provider invoices.
