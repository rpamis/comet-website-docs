Experimental boundary

All 20 samples were included with high confidence. No report was missing, timed out, or excluded. The model, task, validators, execution identity, and run window were shared.

The experiment still covers only one task. It supports conclusions about cost and failure surfaces for this three-decision task, not universal reliability. Follow-up work should vary the number, dependency, and ambiguity of decisions and test whether missing Batch confirmation remains reproducible.
