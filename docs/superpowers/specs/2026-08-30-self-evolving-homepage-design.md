# Self-evolving 首页专题设计

## 目标

在中文首页的 Supervisor Change 专题之后、Why Comet 之前增加 `Self-evolving` 专题。专题用产品化语言说明 Comet 如何把任务经验沉淀为个人记忆和项目知识，并通过抽象动效表现 Experience、Reflection、Context Activation 与 Outcome Feedback 组成的持续演进闭环。

本次只修改中文首页。英文首页留待中文效果确认后同步。

## 产品信息

专题标签使用 `Self-evolving`，主标题使用“每一次任务，都让 Agent 更懂你与项目”。正文先说明 Comet 会把用户反馈、任务结果、Review、验证和归档中的可复用经验沉淀为后续任务上下文，再分别说明两项能力：

- **个人记忆**：保存未来任务仍有帮助的个人偏好、协作方式和经验证的个人经验。系统只在相关任务中提供内容，并根据后续应用结果持续校准。
- **项目知识**：从当前代码、配置、Review、验证和归档中建立可追溯的项目模型与项目规范。来源变化或失效后，相关内容停止提供给 Agent。

文案必须保留以下边界：当前用户要求、系统约束以及当前代码、配置和测试始终高于历史记忆；个人记忆不会自动复制为团队项目知识；专题不宣称训练模型、自动改写 Skill 或无限制保存完整会话。

专题的“了解自进化机制”链接指向现有 `/zh/plugins/agent-learning-loop`，不新增导航页面。

## 页面结构

专题使用一个完整宽度区块，延续首页现有编辑式产品叙事：

1. 左侧为标签、标题、说明、个人记忆与项目知识两个紧凑能力条目，以及“了解自进化机制”链接。
2. 右侧为抽象的经验回路动效，不模拟 Dashboard，也不使用虚构统计数据。
3. 桌面端采用不对称双栏，让动效图案获得略多空间；窄屏改为文案在上、图案在下。

区块与 Supervisor Change、Why Comet 之间使用现有分隔线和纵向间距，不新增孤立的营销卡片视觉。

## 动效图案

图案按一条可读的数据流组织：

1. Experience 节点从任务、反馈、Review 和 Verify 汇入中心 Reflection 节点。
2. 路径分化为两套形态：个人记忆使用柔性的同心轨道和呼吸节点；项目知识使用更稳定的网格、连接线和结构节点。
3. 两条路径汇入下一次任务的 Context 节点，表示相关内容按需进入 Agent 上下文。
4. 一条 Outcome Feedback 弧线返回起点，表示实际应用结果继续校准后续选择。

连续动效使用 CSS/SVG 完成，不增加第三方运行时依赖。粒子沿路径移动，节点以低幅度呼吸，连接线按顺序显现；完整循环保持缓慢、克制，不制造霓虹或粒子爆炸效果。已有 Reveal Controller 只负责专题进入视口时的整体显现。

在 `prefers-reduced-motion: reduce` 下停止循环和位移动画，保留一帧完整、可理解的静态关系图。图案本身为装饰性内容，不向辅助技术重复正文；可见文字保持真实 DOM 文本。

## 视觉系统

- 颜色：复用现有 `--bg`、`--bg-alt`、`--surface`、`--ink`、`--muted`、`--line` 和 `--blue`，仅通过透明度和 `color-mix()` 派生层级，不增加新的主色。
- 字体：标题沿用 Newsreader、Noto Serif SC 与现有衬线回退；正文沿用首页无衬线体系；机器标签使用现有等宽字体。
- 圆角与边界：复用 18px 主圆角和现有细边框；图案容器使用低对比底色与克制阴影。
- 间距：复用首页 section 的流体纵向间距；移动端保留至少 1rem 安全边距。
- 动效：进入动效沿用 760ms 和现有 `--ease`；循环图案使用约 8–12 秒的错峰节奏。

## 实现边界

- 在 `zh/home.mdx` 中插入专题结构，位置固定在 Supervisor Change 之后。
- 动效结构优先封装为单独的 JSX snippet，使首页 MDX 保持可读；样式仍集中在 `custom.css` 的 Comet homepage 作用域内。
- 不修改 `docs.json`，不增加依赖，不修改英文首页，不更改 Supervisor Change 或其他首页专题。
- 工作区存在并行修改时，实施前重新读取 `zh/home.mdx`、`custom.css` 和相关 snippets，只合并本专题需要的最小改动。

## 降级与失败行为

- JavaScript 未运行时，专题正文和静态图案仍然可见；循环动效不依赖 JavaScript。
- CSS 动画不可用或用户要求减少动态效果时，页面展示完整静态状态。
- 图案尺寸通过 `viewBox` 和 CSS 布局适配，不依赖固定桌面宽度；窄屏不得产生横向滚动或文字截断。

## 验收与验证

- 文案准确区分个人记忆与项目知识，并符合 Comet 当前源码和 Specs 的能力边界。
- 专题出现在 Supervisor Change 之后、Why Comet 之前，英文首页保持不变。
- 桌面、平板和约 390px 移动视口无横向溢出，标题、能力条目和图案层级清晰。
- 浅色与深色主题下边框、文字和动效节点具有足够对比度。
- `prefers-reduced-motion` 下没有持续动画，静态图案仍能表达完整闭环。
- 页面没有浏览器控制台错误或警告。
- 运行 Mintlify 校验及与修改范围相称的链接、格式和页面预览检查。
