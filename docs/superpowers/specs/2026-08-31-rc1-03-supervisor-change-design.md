# RC1 03 Supervisor Change 视觉设计

## 目标

重新生成 `img/rc1-highlights-v2/03-supervisor-change.png`，用抽象且易懂的方式表达 Supervisor Change 如何统筹一个复杂目标：按独立交付结果拆分、管理依赖、推进并行验证，最后汇聚为一个完成统一验收的成果。

新图需要与 `08-platforms.png` 建立明确区分。画面不再使用环形平台节点、像素消散、右下深色星球或平台能力图标。

## 核心文案

图片只使用以下主要文案：

- `Supervisor Change`
- `复杂目标，一次统筹交付`
- `拆分独立成果 · 管理依赖 · 并行验证 · 汇聚验收`

视觉中的短标签可使用：

- `Goal`
- `Child A`
- `Child B`
- `Child C`
- `Final Verify`

短标签只承担结构解释，不增加产品结论或虚构数据。

## 核心视觉

采用“扁平编排轨道”表达 Supervisor Change：

1. 画面上方或中上部放置一个扁平的 `Goal` 入口模块。
2. `Goal` 进入一条标识 Supervisor 统筹层的宽蓝色色带，再分成三条平面执行轨道。三条轨道分别代表可以独立实现和验证的 child。
3. 三条轨道使用错位起点、短连接和明确的前后节奏表达依赖关系。连接保持克制，只显示理解依赖所需的结构。
4. 每条轨道经过一个与 v2 统一的扁平描边勾选节点，表示该 child 已独立验证。
5. 三条轨道在下部汇聚成一条完整交付带，终点使用扁平盾牌或圆形勾选图标，并以 `Final Verify` 标识统一验收。

整个视觉表现从“一个目标”到“多个独立结果”，再回到“一个完整交付”的闭环。图形以平面色带、描边轨道、圆形状态点和少量箭头为视觉语言。画面不使用发光管线、悬浮光环或半 3D 几何体。

## 构图

画布为严格 3:4 纵向比例，纯白 `#FFFFFF` 背景。

- 左上角使用仓库现有 Comet 图标，保持原始比例。
- 标题区位于上方，`Supervisor Change` 是主标题，中文产品句作为紧邻说明。
- 主视觉占据画面中部和下部约三分之二空间，扁平轨道从一个入口展开，再向一个成果收束。
- 汇聚成果位于视觉重心附近，不放在右下角，不形成与 08 相同的星球构图。
- 保留充足白色留白，不使用密集节点、卡片网格或复杂 Dashboard 框架。

## 色彩与字体

- 背景与四角必须是精确 `#FFFFFF`。
- 主文字使用深墨黑，轨道使用 Comet 蓝、青蓝与少量浅蓝灰建立层次。
- 统一验收结果可以使用克制的青绿色或黄绿色点亮，但不使用大面积荧光色。
- 中文和英文使用自然宽高比的现代无衬线字体，禁止纵向拉伸和非等比缩放。
- 只使用轻微的局部蓝色渐变建立色带层级。禁止外发光、体积光、玻璃质感、悬浮投影和半透明光环。

## 与 v2 的统一语言

- 标题沿用 02、05、06、07 的深蓝粗体无衬线字和清晰字号层级。
- 图形沿用 06、07 的平面蓝色描边、白色内部、圆形节点和克制箭头。
- 验收通过沿用 v2 的少量绿色状态点，不绘制发光绿色立方体。
- 模块圆角、线宽和留白保持产品信息图尺度，不模拟真实 UI，也不做概念科技海报。

## 与 08 的差异边界

03 禁止出现以下元素：

- 环绕中心数字的平台图标圈；
- Skills、Rules、Hooks 平台层级；
- 右下深色星球、弧面或大面积深蓝区域；
- 大量像素方块消散；
- 平台数量、Hook 数量或安装命令；
- 四列或多列重复的 Child 流程卡片。
- 发光管线、悬浮光环、立体球体、立方体和体积光。

03 的视觉识别必须来自“分解、依赖、并行、汇聚”，08 的视觉识别继续来自“多平台覆盖”。

## 文案限制

- 使用直接的产品化陈述句。
- 不使用反问句、“不是……而是……”“而不是”或先否定再解释的句式。
- 不增加并行倍数、节省时间、Agent 数量或成功率等未提供的数据。
- 不使用“一个 Agent 扛所有任务”等带情绪或对立感的表达。

## 验收标准

1. 输出文件覆盖 `img/rc1-highlights-v2/03-supervisor-change.png`。
2. PNG 宽高比严格等于 3:4，尺寸适配只使用等比缩放与纯白留边。
3. 背景、四角和完整画布边界为精确 `#FFFFFF`。
4. 标题与中文文案完全正确，短标签无乱码、重复字符或拼写错误。
5. 字体保持自然比例，无纵向拉伸。
6. 画面清楚表达一个目标分成多个 child、按依赖推进、分别验证并汇聚完成最终验收。
7. 画面不包含 08 的环形平台网络、像素星球或平台图标语言，也不包含发光、悬浮或半 3D 效果。
8. 提交前检查最终图片、尺寸、边界像素、Git diff 和提交范围；只提交本设计、实施计划和 03 图片相关文件。
