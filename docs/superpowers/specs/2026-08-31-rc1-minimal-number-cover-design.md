# RC1 极简数字封面设计

## 目标

重做 `img/rc1-highlights-v2/01-cover-20-betas.png`。封面只突出版本、时间和累计数据，删除当前复杂的平台模块、系统连接图、界面缩略图与图标墙。

## 画面结构

- 使用 3:4 竖版画布和纯白背景。
- 顶部保留小尺寸 Comet Logo 与 `Comet 0.4.0 RC1`。
- 中央以 `2 个月` 作为第一视觉焦点。
- 下方展示 `20 个 Beta 版本`、`50 个合并 PR`、`24 位累计开发者`。
- 时间进程使用抽象的渐进节奏表达，例如疏密变化的蓝色节点、柔和弧形或由浅到深的形态序列；不使用常规折线图、坐标轴或复杂版本刻度。

## 视觉规则

- 数字醒目，文字保持正常宽高比例，避免纵向拉伸和超窄字体。
- 使用深海军蓝、Comet 蓝和少量青绿色完成态点缀。
- 允许少量抽象几何形状增强层次，元素总量保持克制。
- 不使用卡片墙、产品模块图、平台 Logo、Dashboard 缩略图、代码窗口、复杂连线或伪造提交哈希。
- 中文文案采用直接的产品化陈述，不使用反问句和“不是……而是……”句式。

## 验收

- 文案与数字准确且可读。
- 背景为精确的 `#FFFFFF`。
- 最终图片宽高比为 3:4，所有主体保持自然比例。
- 页面第一眼聚焦 `2 个月`，随后自然读取 20、50、24 三项数据。
- Git 仅覆盖 v2 目录中的 01 图片及本设计说明。
